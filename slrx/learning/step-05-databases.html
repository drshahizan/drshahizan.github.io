Step 05 of 10

Search the Databases

Run each approved query consistently and preserve a complete audit trail.

For every database

  1. Record the database, platform, and search date.
  2. Paste the exact final query and document all filters.
  3. Record the number of results before export.
  4. Export complete bibliographic metadata, abstracts, DOI, and keywords.
  5. Use a consistent format such as CSV, RIS, or BibTeX.
  6. Store the original export without manual deletion.
Minimum search log

Database · platform · date · coverage period · fields searched · exact query · filters · results · export filename.

Quality check

  • All searches follow the approved protocol.
  • Search dates and result counts are recorded.
  • Files are named consistently and preserved.
  • Searches can be updated later using the same logic.

Required output

Search Log and Records

  • One row per database
  • Exact search queries
  • Result counts
  • Original export files
  • Total records identified

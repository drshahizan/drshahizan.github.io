# Polishing Your Draft Article Using AI Tools

Session website for the **Winning Journal Writing Workshop 2026**, a collaborative programme between Universiti Teknologi Malaysia (UTM) and Ho Chi Minh City University of Technology (HCMUT), Vietnam.

- **Date:** Friday, 6 November 2026
- **Time:** 9:00 AM – 1:00 PM (MYT)
- **Platform:** Cisco Webex (online)
- **Speaker:** Assoc. Prof. Dr. Mohd Shahizan, UTM

## File structure

```
index.html            Home page (required by GitHub Pages)
session.html          Session outline
modules.html          Overview of the 12 modules
modules/              One page per module (M01–M12)
prompts.html          Prompt library with copy buttons
tools.html            AI tools by category
activities.html       Six online-ready hands-on activities
checklist.html        Interactive pre-submission checklist
resources.html        Ethics guidance, publisher policies, verification tools
404.html              Error page
assets/css/style.css  Stylesheet
assets/js/main.js     Menu, theme toggle, checklists, copy buttons, prompt filters
assets/favicon.svg    Site icon
.nojekyll             Disables Jekyll processing on GitHub Pages
```

## Publishing on GitHub Pages

1. Create a new public repository.
2. Upload all files and folders above, keeping the folder structure.
3. Go to **Settings → Pages**, set the branch to `main` and the folder to `/ (root)`, then save.
4. The site will be live at `https://<username>.github.io/<repository-name>/`.

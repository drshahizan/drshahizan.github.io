AI tools

Tools covered in the session, grouped by task. Features and pricing change quickly, so check each tool's official website.

General-purpose chatbots (LLMs)

Flexible for language editing, restructuring and simulated review. Always verify facts and references.

ToolMain use
ChatGPTLanguage editing, restructuring, reviewer simulation
ClaudeLong documents, argument analysis, edits with explanations
GeminiLanguage editing, Google Workspace integration
Microsoft CopilotEditing inside Word and Microsoft 365

Academic writing assistants

Trained or configured for academic style; well suited to final language checks.

ToolMain use
PaperpalAcademic language checks and submission readiness
WritefullAcademic language editing, titles and abstracts
TrinkaAcademic and technical grammar
GrammarlyGrammar, clarity and tone
QuillBotParaphrasing; use with caution

Literature search and synthesis

Help you find and understand studies; no substitute for reading the original sources.

ToolMain use
ElicitPaper search and data extraction
ConsensusEvidence-based answers with sources
SciteCitation context: supporting or contrasting
SciSpaceReading and explaining papers
Semantic ScholarFree academic search engine
ResearchRabbitMapping connections between papers
Connected PapersVisual graphs of related papers

References and integrity

Manage citations and check similarity before submission.

ToolMain use
ZoteroFree, open-source reference manager
MendeleyReference manager from Elsevier
EndNoteReference manager from Clarivate
Turnitin / iThenticateText similarity checking (iThenticate is used by publishers)

Journal selection

Match your manuscript with journals whose scope fits.

ToolMain use
Web of Science Master Journal ListConfirm a journal's Web of Science indexing
Elsevier Journal FinderElsevier journal suggestions from your abstract
Springer Nature Journal SuggesterSpringer Nature journal suggestions

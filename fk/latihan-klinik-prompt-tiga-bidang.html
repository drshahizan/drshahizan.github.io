01

Pilih kes kerja

Bertindak sebagai fasilitator klinik prompt. Cadangkan tiga kes tugasan staf Fakulti Komputeran UTM: satu Sumber Manusia, satu Sokongan Teknikal dan satu Pengurusan Akademik.

Bagi setiap kes, nyatakan masalah, pengguna output, input diperlukan, data sensitif yang perlu dielakkan, hasil akhir dan kriteria kejayaan. Jangan hasilkan prompt penyelesaian lagi.
02

Hasilkan prompt awal

Untuk kes yang dipilih, tulis satu prompt awal maksimum 30 patah perkataan. Senaraikan maklumat yang hilang dari segi Peranan, Tugasan, Konteks, Format dan Kekangan. Jangan baiki prompt itu lagi.
03

Bina prompt lengkap

Baiki prompt awal menggunakan PERANAN, TUGASAN, KONTEKS, FORMAT OUTPUT dan KEKANGAN.

Masukkan arahan supaya AI tidak mereka nama, angka, polisi atau keputusan; menandakan maklumat hilang sebagai [PERLU DISAHKAN]; membezakan fakta daripada cadangan; dan menyediakan senarai semak manusia.
04

Uji A/B

Uji Prompt A dan Prompt B menggunakan input contoh sama yang telah dinyahpengenal. Nilai ketepatan, kelengkapan, struktur, nada, kebolehgunaan dan risiko rekaan fakta.

Hasilkan jadual skor 1–5, bukti, kelemahan dan pembaikan. Jangan memberi skor tanpa bukti khusus.
05

Audit silang

Bertindak sebagai penyemak rakan daripada bidang lain. Audit prompt tanpa melaksanakan tugasan. Semak skop, input, format, kekangan, privasi, andaian, kriteria kualiti dan titik kelulusan manusia.

Kelaskan isu sebagai KRITIKAL, MAJOR atau MINOR dan cadangkan pindaan tepat.
06

Templat guna semula

Gabungkan pembaikan diluluskan. Hasilkan PROMPT MUKTAMAD dan TEMPLAT GUNA SEMULA dengan ruang [ISI DI SINI].

Sertakan tujuan, input dibenarkan, input dilarang, output dijangka, lima kriteria penerimaan, senarai semak manusia dan sejarah versi.

# Setiausaha Pintar dan Produktif dengan Kecerdasan Buatan

Laman web statik rasmi bertemakan korporat Universiti Teknologi Malaysia, dibina menggunakan HTML5, CSS3 dan JavaScript ES6 untuk GitHub Pages.

## Terbitkan di GitHub Pages

1. Salin semua fail dan folder dalam direktori ini ke repositori GitHub.
2. Buka **Settings > Pages**.
3. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Simpan dan tunggu pautan GitHub Pages diaktifkan.

## Struktur

- `index.html` - kandungan dan struktur semantik
- `panduan-ai.html` - panduan semakan, keselamatan data, latihan dan checklist
- `prompt-ai.html` - formula, proses, pembina interaktif dan perpustakaan 35 prompt
- `sumber-ai.html` - contoh hasil, templat pentadbiran, storyboard, kuiz, glosari dan FAQ
- `style.css` - sistem reka bentuk UTM dan responsif
- `script.js` - carta, galeri, tab, carian dan interaktiviti
- `panduan-ai.js` - kawalan tema dan navigasi panduan
- `prompt-ai.js` - carian, penapisan, salinan dan pembina prompt interaktif
- `sumber-ai.js` - salinan templat, kuiz kendiri, kawalan tema dan navigasi halaman sumber
- `prompts.js` - pustaka 35 prompt Google Gemini dalam tujuh kategori
- `assets/slides/` - semua visual yang diekstrak daripada slaid kursus
- `manifest.json` dan `service-worker.js` - sokongan PWA dan luar talian

Kemaskini URL kanonik, sitemap dan pautan sosial jika nama repositori berubah.

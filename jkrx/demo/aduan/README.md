# JalanCare JKR Rembau

Prototaip statik Sistem Pengurusan Aduan JalanCare JKR Daerah Rembau.

## Cara membuka

1. Ekstrak fail ZIP.
2. Buka `index.html` untuk Portal Awam.
3. Buka `login.html` untuk Portal Dalaman atau klik **Log Masuk Staf**.
4. Akaun latihan: `admin` / `jkr123`.

Semua halaman boleh digunakan secara statik tanpa pangkalan data. Borang, muat naik dan penyimpanan data ialah demonstrasi antaramuka.

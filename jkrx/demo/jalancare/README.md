# JalanCare JKR Rembau

Prototaip latihan berbilang halaman untuk GitHub Pages.

## Terbitkan ke GitHub Pages

1. Muat naik semua kandungan folder `jalancare` ke repositori GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, kemudian `main` dan `/root`.
4. Buka URL GitHub Pages yang diberikan.

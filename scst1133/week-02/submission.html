Student checklist

  • I can sign in to all required tools.
  • I have completed my GitHub profile using a professional identity.
  • I have installed and authenticated GitHub Desktop.
  • I have created the required public repository.
  • I have used headings, links, images, a table and checklist in README.
  • I have published a working GitHub Pages website.
  • I have created and shared a Figma design.
  • I have recorded my Google Stitch prompt and output.
  • I have created and shared a 60–90 second Google Vids presentation.
  • I have written a short learning reflection.
  • I have tested every submitted link in a private browser window.
!

Do not submit inaccessible links. A link that requires the lecturer to request permission will be treated as incomplete until access is corrected.

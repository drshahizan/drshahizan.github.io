Core references

The main references for this course. Start with Fundamentals of Data Engineering.

Book · main textPaid

Fundamentals of Data Engineering

Reis, J. and Housley, M. (2022). Sebastopol, CA: O’Reilly Media.

The framework used throughout the course: the data engineering lifecycle (generation, storage, ingestion, transformation, serving) and its undercurrents.

O’Reilly ↗
BookFree

The Elements of Big Data Value

Curry, E., Metzger, A., Zillner, S., Pazzaglia, J.-C. and García Robles, A. (eds.) (2021). Cham: Springer.

Open-access book on the big data value ecosystem: technical architectures, data-driven innovation, skills, policy and business models.

Springer ↗Free PDF (OAPEN) ↗
PaperFree

Defining Architecture Components of the Big Data Ecosystem

Demchenko, Y., De Laat, C. and Membrey, P. (2014). Proc. International Conference on Collaboration Technologies and Systems (CTS), 104–112.

Proposes the Big Data Architecture Framework: infrastructure, analytics, data models, lifecycle management and security.

IEEE (DOI) ↗Free manuscript (UvA) ↗
BookVia UTM Library

Data Engineering for Modern Applications

Praveen, R. V. S. (2024). Addition Publishing House.

Additional reference on applying data engineering in modern applications.

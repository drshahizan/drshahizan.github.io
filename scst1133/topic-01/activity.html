SCST1133 · Topic 01

Integrated System Analysis

Apply Topic 01 concepts to one familiar digital service.

01Introduction to Computer and System
Hands-on activity

Analyse a familiar service as a computer system

Focus on the system purpose, technical components, relationships, constraints and responsible operation.

Complete the analysis

Select a service

Choose UTM Smart, course registration, online banking, Grab, Shopee, a library service or another familiar system.

Define the system

State its purpose, principal users and system boundary.

Trace the operation

Identify input, processing, storage, output and feedback.

Map the components

Identify relevant hardware, software, operating-system, network and cloud components.

Evaluate the system

Identify one bottleneck, one security or privacy risk and one improvement.

Required artefact

SectionEvidence
System diagramPurpose, boundary and connected components
OperationInput-to-feedback explanation
Component tableHardware, software, storage and networks
EvaluationOne bottleneck and one responsible-use risk
ImprovementOne realistic recommendation with expected benefit
Reflection100–150 words on what the analysis revealed

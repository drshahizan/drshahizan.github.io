SCST1133 · Topic 01

Internet and World Wide Web

Separate the global network infrastructure from the web services that operate across it.

01Connected Systems
Required pathway

The Web uses the Internet, but they are not the same

The Internet connects networks and devices. The World Wide Web is one service that uses this infrastructure to deliver linked resources through browsers.

Essential distinctions

TermFunction
InternetA global network of interconnected networks using standard communication protocols.
World Wide WebA system of linked webpages and resources accessed through the Internet.
Web browserA client application that requests, interprets and presents web content.
Web serverA computer or service that responds to web requests.
URLAn address identifying the protocol, domain and path of a resource.
HTTP/HTTPSProtocols used to exchange web requests and responses; HTTPS adds encrypted transport.
DNSA distributed naming system that maps domain names to network addresses.

How a web request travels

1 · Enter URL→2 · Resolve DNS→3 · Connect securely→4 · Send request→5 · Server responds→6 · Browser renders

The response may trigger further requests for stylesheets, scripts, fonts, images and data.

Web milestones in context

  • Early websites demonstrated linked documents using simple HTML.
  • Graphical browsers made text and images accessible through one interface.
  • Search engines improved discovery across rapidly expanding web content.
  • Modern web applications combine client code, APIs, databases, cloud infrastructure and security controls.

Security: HTTPS protects data in transit, but it does not guarantee that a website is trustworthy. Users must still verify the domain, content and requested permissions.

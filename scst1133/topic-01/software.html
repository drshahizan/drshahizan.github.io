System and Application Software

Understand how software layers translate user goals into operations performed by hardware.

01Introduction to Computer and System
Software

Software gives hardware useful instructions

System software manages the environment while application software performs user-oriented tasks.

Software categories

CategoryPurposeExamples
Operating systemManage hardware and provide common servicesWindows, macOS, Linux, Android
Application softwarePerform tasks for usersBrowser, Figma, spreadsheet
Utility softwareMaintain, protect or optimise the systemBackup, antivirus, compression
DriverAllow the operating system to control a devicePrinter or graphics driver
FirmwareProvide low-level control inside a deviceRouter or device firmware

01Introduction to Computer and System
Reference

Key terms in one place

Use the glossary to distinguish hardware, software, network and system-thinking concepts.

TermMeaning
Computer systemA connected combination of hardware, software, data, users and procedures serving a purpose.
HardwarePhysical components of a computing system.
SoftwareInstructions and programs executed by hardware.
CPUThe processor that executes instructions and coordinates operations.
RegisterVery small, fast storage used directly by the CPU.
CacheFast memory holding frequently required instructions and data.
RAMVolatile memory used by active programs.
StoragePersistent retention of files and applications.
Operating systemSystem software that manages resources and common services.
DriverSoftware enabling an operating system to control a device.
FirmwareLow-level software stored within a device.
ProcessA program currently being executed.
ClientA device or application requesting a service.
ServerA system providing data or functionality.
NetworkConnected devices that exchange information or resources.
Cloud serviceRemote computing or storage accessed through a network.
System boundaryThe distinction between the system and its environment.
FeedbackInformation about a result used to guide the next action.
BottleneckA constraint limiting overall system performance.
AuthenticationVerification of a user or system identity.
BackupA recoverable copy of important information.
Information Technology (IT)Hardware, software, storage and networks used to create, process, store and exchange information.
ICTInformation technology with explicit emphasis on digital communication and connectivity.
Information systemA socio-technical system combining people, processes, data and technology for operations and decisions.
World Wide WebA service of linked resources accessed through the Internet using web protocols.
DNSA distributed system that maps domain names to network addresses.
VirtualisationThe abstraction of physical resources into isolated software-defined computing environments.
Internet of ThingsConnected sensors, devices and actuators that exchange operational data.
Edge computingProcessing located near a data source to reduce latency and unnecessary network transfer.

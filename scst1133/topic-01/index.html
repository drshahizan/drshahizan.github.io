Introduction to Computer and System

Understand how hardware, software, information, networks and users work together as one purposeful system.

01Introduction to Computer and System
Module overview

See the whole computer system

Topic 01 establishes the computing foundation needed for every later topic.

Learning outcomes

  • Explain the purpose and basic operation of a computer system.
  • Identify major hardware and software components.
  • Trace information through input, processing, storage, output and feedback.
  • Explain operating-system and network roles.
  • Apply system thinking to a familiar digital service.
  • Evaluate performance and responsible-use considerations.

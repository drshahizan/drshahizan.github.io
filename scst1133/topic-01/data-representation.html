Digital Data Representation

See how text, numbers, images, audio and video become data that computers can process and store.

Core concepts

ConceptMeaningExample
BitA binary value: 0 or 1One state in digital representation
ByteA group of eight bitsA basic unit of storage
EncodingRules for representing informationUTF-8 text encoding
File formatA defined structure for stored dataCSV, JPEG, MP3 or MP4
MetadataInformation describing dataFile type, size and creation time

Data engineering connection: File format, encoding and metadata affect how data is ingested, validated, transformed and exchanged.

Types of Data

Data comes in many shapes. Recognising its structure tells you how to store and process it.

13Data types
Data landscape

Structured, semi-structured and unstructured

Data includes facts and observations about people, places, things and events, as well as audio, music, photographs and video.

TypeCharacteristicsExamplesTypical formats
StructuredFixed schema; organised in rows and columns; easy to search and analyse with SQLStudent records, bank transactions, sensor readings in a tableRelational tables, CSV, Excel
Semi-structuredNo rigid table, but uses tags or keys to describe the data; structure can vary between recordsAPI responses, app event logs, email headersJSON, XML
UnstructuredNo predefined model; needs special processing to analyseDocuments, photos, audio, video, social-media postsTXT, PDF, JPG, MP3, MP4

A note on file formats

Files are still a universal way to exchange data. Reis and Housley note that the same format can hold different types: CSV is usually structured but can be messy, while JSON and XML are semi-structured. Data engineers later convert files into analytics-friendly formats such as Parquet—covered in Topic 12.

Why Databases?

Like a library for data: organised, shared, secure and consistent.

16Databases
Data landscape

From scattered files to integrated data

A database is an electronic collection of integrated, logically related data that can be easily accessed, manipulated and updated.

BenefitMeaningCampus example
SharingMany users and applications use the same dataSecurity office and students’ app read the same permit data
SecurityAccess can be controlled by roleOnly enforcement officers can issue summonses
Less data redundancyData is stored once rather than copied in many filesA student’s plate number is stored in one place
Data integrityData stays accurate and consistentA summons must refer to a valid permit

Without a database

If each office keeps its own spreadsheet, the same student’s details may be typed several times, updated in one place and not another, and shared by email. Recall the Public Health England case from Topic 03.

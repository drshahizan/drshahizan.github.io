Optional case study

Airbnb and Apache Airflow

A growing company needed to manage an exploding number of data jobs—so it built an orchestrator and shared it with the world.

O3Airflow
Optional · Orchestration

Orchestration becomes a discipline

As Airbnb grew, its data team ran more and more jobs that depended on each other. Scheduling them by hand, or with simple time-based tools, became unreliable.

Key ideas

  • Pipelines as code: workflows are written in Python, so they can be version-controlled, reviewed and tested like software.
  • Dependencies as a graph: a task runs only when the tasks it depends on have succeeded.
  • Recovery: failed tasks can be retried automatically, and the team is alerted.
  • Open source from the start: other companies adopted and improved it, and today it is offered as a managed cloud service.

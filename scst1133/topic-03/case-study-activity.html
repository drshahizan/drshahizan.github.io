Step 2 · Answer, publish and submit

Answer in Canva

Answer every question for your case in a Canva design (document, poster or infographic). Support each answer with evidence from the case and ideas from Topic 3.

Download as PDF

In Canva, select Share › Download › PDF Standard. Name the file with your group code and case, for example S03-G1_Topic3_Uber.pdf.

Upload to your group’s github.io site

Upload the PDF to your group’s GitHub repository with GitHub Pages turned on (Settings › Pages › Deploy from a branch › main). Your link will look like https://username.github.io/repository/S03-G1_Topic3_Uber.pdf. See the GitHub Pages guide ↗.

Test the link

Open the link in a private (incognito) window. The PDF must open without signing in.

Submit the link

On the submission page, choose Topic 3 · Case-study task, select your assigned case and paste the github.io link. Any group member may submit. No e-Learning submission is needed.

Content checklist

  • Group code (for example S03-G1), group name and all members’ names
  • Name of your assigned case
  • Every question for your case answered and numbered
  • Evidence from the case page and links to Topic 3 concepts
  • A list of sources used

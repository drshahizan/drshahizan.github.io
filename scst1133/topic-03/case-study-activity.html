Step 10 · Assess

Case-Study Task

Analyse the two required cases and present one optional case using the Topic 03 lens.

10Case task
Group task · 10 marks

Apply the Topic 03 lens

Work in groups of four or five. Parts A and B are written; Part C is a three-minute presentation in class.

Task structure

Part A · Uber (written)

Match each generation to an FDE era, map the lifecycle for Generation 2, identify the weakest undercurrent in Generation 1 and explain the scalability–freshness trade-off.

Part B · KKM COVID-19 open data (written)

Map the five lifecycle stages, give one requirement for each undercurrent and evaluate the privacy risk of publishing data derived from MySejahtera check-ins.

Part C · One optional case (presentation)

Your lecturer assigns each group one of the five optional cases. Present it in three minutes using the four lens questions: era, lifecycle stage, undercurrent and trade-off.

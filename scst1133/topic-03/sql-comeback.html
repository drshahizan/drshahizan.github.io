The Comeback of SQL

A language from the 1970s is still one of the most important skills in modern data engineering.

E3SQL
Extension

Sidelined, then everywhere

SQL is the clearest example of the theme “what’s old is new again”.

EraRole of SQL
Relational databases and data warehousingThe standard way to query and manage business data.
Early big dataPushed aside as engineers wrote custom MapReduce code in Java and other languages.
TodayBack at the centre through Spark SQL, BigQuery, Snowflake, Hive and SQL support in streaming frameworks such as Flink, Beam and Kafka.

Why SQL keeps winning

  • It is declarative: you describe what result you want, and the system decides how to compute it.
  • It can scale to massive data when the engine underneath is distributed.
  • Analysts, engineers and scientists can share the same language.

Know its limits

SQL is not the answer to everything. A skilled engineer recognises when another tool is better—for example, using Spark code for complex text processing instead of forcing it into SQL.

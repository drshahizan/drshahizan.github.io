Required case study 2 · Malaysia

Malaysia’s COVID-19 Open Data on GitHub

A national data pipeline that turned daily reports from across the country into public, machine-readable files.

C2KKM data
Required · Lifecycle and undercurrents

A public pipeline in a national emergency

In mid-2021, Malaysia’s Ministry of Health (KKM) began publishing detailed, de-identified pandemic data in a public GitHub repository. It complemented the vaccination data repository launched in June 2021.

At a glance

OrganisationMinistry of Health Malaysia (KKM)
LaunchedJuly 2021 (vaccination data from June 2021)
PlatformPublic GitHub repository MoH-Malaysia/covid19-public
FormatCSV files organised into folders: epidemic, mysejahtera, vaccination and static
FrequencyDaily; data correct as of 23:59 of each date unless stated otherwise
Topic 03 link04 Lifecycle · 05 Undercurrents · 07 Toolkit

What was published

FolderExamples of data
epidemicCases and testing; healthcare capacity (quarantine centres, hospitals, ICU); deaths
mysejahteraCheck-ins and contact-tracing data from the MySejahtera app
vaccinationVaccinations by state, district, age, sex and other categories
staticReference data such as population by state, based on the 2020 census

Why this case matters

  • Every lifecycle stage is visible: thousands of daily reports are generated, collected, stored, cleaned and served as files anyone can download.
  • The undercurrents are under public scrutiny: records had to be de-identified (security), definitions documented (data management) and updates delivered every day (DataOps and orchestration).
  • It uses the same GitHub and version-control skills you learned in Topic 02, and the CSV format introduced in Topic 04.
  • Researchers, journalists and developers built dashboards and analyses on top of it—data engineering serving downstream users at national scale.

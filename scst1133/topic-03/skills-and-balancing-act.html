Step 06 · Describe

Skills and the Balancing Act

A data engineer constantly balances competing goals—and knows where the role ends.

06Skills
Core concept

Juggling many moving parts

A data engineer’s skill set covers the undercurrents, knowledge of how data is produced in source systems, and an understanding of how analysts and data scientists will use it.

Six goals to balance

GoalQuestion it raises
CostCan we afford to build and run this solution?
AgilityHow quickly can we change it when needs change?
ScalabilityWill it still work when data or users grow?
SimplicityCan the team understand and maintain it?
ReuseCan parts be used again elsewhere?
InteroperabilityWill it work with other tools and systems?

Then and now

Recent past

Low-level specialists

Engineers mastered a few powerful, monolithic technologies and spent much of their time administering clusters and managing overhead.

Today

Balancing best-of-breed services

Modern tools hide much of that complexity. Engineers choose the simplest, most cost-effective services that deliver value and design architectures that can evolve.

What a data engineer typically does not do

A data engineer usually does not directly build machine learning models, create reports or dashboards, perform data analysis, define key performance indicators or develop software applications.

However, they should understand these areas well enough to serve the people who do.

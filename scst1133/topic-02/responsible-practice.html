02Digital Tools
Safety · ethics · integrity

Professional practice across all tools

A technically successful project is incomplete if it exposes private data, misrepresents AI-generated work or uses unsafe sharing settings.

Protect secrets

Never commit passwords, access tokens, API keys or private configuration files. Use placeholder values in examples.

Protect personal data

Do not upload student records, identification documents, private contact details or confidential datasets.

Use appropriate permissions

Test GitHub, Figma and video links in a private browser window and grant only the access required.

Respect licences

Credit external code, images, templates and datasets, and comply with their stated licences.

Disclose AI assistance

Identify where generative AI was used and explain the human evaluation, correction and refinement performed.

Maintain authenticity

Do not claim team work, generated content or copied designs as solely your own contribution.

Pre-publication safety check

  • No token, password, student record or private document is present.
  • Repository visibility matches the project purpose.
  • External sources and AI assistance are acknowledged.
  • Every sharing permission has been tested.
  • Profile information is professional and appropriate for public viewing.

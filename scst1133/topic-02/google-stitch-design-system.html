Starter DESIGN.md

# Design System
## Colour
- Primary: #102A63
- Success: #16A34A
- Warning: #F59E0B
- Error: #DC2626
## Components
- Buttons use an 8 px radius.
- Cards use 24 px padding.
- Error states include an icon and text.
## Accessibility
- Maintain readable contrast.
- Provide visible keyboard focus.

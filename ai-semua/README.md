# AI untuk Semua — GitHub Pages

Fail ini ialah laman statik yang boleh diterbitkan terus melalui GitHub Pages.

## Cara menerbitkan

1. Ekstrak fail ZIP.
2. Muat naik semua kandungan folder ke repositori GitHub.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch **main**, folder **/(root)** dan klik **Save**.

Pastikan semua fail HTML kekal di direktori utama repositori. Pakej ini merangkumi halaman utama, modul, latihan, video 10 saat, AI Tools dan perpustakaan 60 prompt. Semua prompt mempunyai fungsi salin.

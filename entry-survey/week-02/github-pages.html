Step 04 · Publish

GitHub Pages

Turn the files in your repository into a public static website.

GPHosting
Web publishing

Publish your first course website

GitHub Pages can host HTML, CSS, JavaScript and media files directly from a repository.

Create the main page

The homepage must be named index.html.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>My Digital Tools Journey</title>
</head>
<body>
  <h1>My Digital Tools Journey</h1>
  <p>Welcome to my SCST1133 learning page.</p>
</body>
</html>

Enable GitHub Pages

Open repository settings

Open the repository, select Settings, and locate Pages.

Select the source

Choose deployment from a branch, select main and the root folder, then save.

Wait for deployment

Check the Pages or Actions status until the deployment completes.

Open the website

Your project URL normally follows https://username.github.io/repository-name/.

Publish updates

Edit locally, commit, push, wait briefly and refresh the website. Use a hard refresh if an older version remains cached.

Troubleshooting checklist

  • The homepage is named exactly index.html.
  • The selected publishing branch and folder are correct.
  • File names and links use matching upper- and lowercase letters.
  • The latest commit was pushed to GitHub.
  • The Pages deployment completed successfully.

Expected output

  • A working GitHub Pages URL.
  • A homepage displaying your name, course and activity.
  • The published URL added to your README.

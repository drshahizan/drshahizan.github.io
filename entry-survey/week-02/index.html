SCST1133 · Guided Learning Module

Digital Tools

Learn how to design, build, publish, document and present a digital solution using four essential platforms.

02Week
Module overview

From an idea to a published solution

This learning path connects GitHub, Figma, Google Stitch and Google Vids in one practical workflow.

Learning outcomes

  • Create, document and manage a GitHub repository.
  • Use GitHub Desktop to commit, push and pull project files.
  • Publish a static website using GitHub Pages.
  • Write structured project documentation using Markdown.
  • Create and share interface designs using Figma and Google Stitch.
  • Produce and share a short technical presentation using Google Vids.
01 · Build

GitHub

Create your repository, manage files, publish a website and document your work.

02 · Design

Figma

Turn your ideas into a structured interface and interactive prototype.

03 · Generate

Google Stitch

Use natural-language prompts to generate and refine interface concepts.

04 · Present

Google Vids

Communicate your process and outcome through a concise technical video.

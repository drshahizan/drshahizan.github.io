# Dataset Latihan Pengurusan Akademik

`dataset-pengurusan-akademik-sintetik.csv` mengandungi 32 baris agregat rekaan merentas lapan semester dan empat kategori isu. Semua angka dicipta khusus untuk latihan; bukan statistik, rekod atau gambaran operasi sebenar Universiti Teknologi Malaysia.

Setiap baris ialah agregat bagi satu kategori isu dan semester. Gunakan data untuk semakan, pengiraan kadar, carta trend dan penerangan dapatan. Jangan jadikan nilai atau pola ini sebagai bukti prestasi sebenar.

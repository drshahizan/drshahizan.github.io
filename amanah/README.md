# Amanah Data dalam Kecerdasan Buatan Generatif

Laman program statik untuk GitHub Pages.

## Halaman

- `index.html` — halaman utama dan sinopsis (kekal di akar repositori untuk GitHub Pages)
- `pages/` — halaman tentatif, bahan pengajaran, persediaan peserta, direktori alat AI, pusat prompt, semakan hasil dan panduan fasilitator
- `pages/prinsip-etika-ai.html`, `pages/klasifikasi-data.html`, `pages/kuiz-kendiri.html` — nota Sesi 1–4 dan glosari, panduan klasifikasi data, kuiz kendiri
- `pages/kunci-jawapan.html` — kunci jawapan Modul 01–08 untuk fasilitator (tidak dipautkan dari menu utama)
- `pages/modul/` — halaman latihan Modul 01 hingga Modul 11
- `css/style.css` dan `js/main.js` — gaya responsif dan interaksi salin prompt
- `assets/latihan/` — fail kajian kes, dokumen simulasi dan dataset analisis sintetik

## Terbitkan melalui GitHub Pages

1. Ekstrak ZIP dan muat naik semua kandungannya ke akar repositori GitHub Pages.
2. Dalam GitHub, buka **Settings → Pages**.
3. Pilih branch dan folder sumber penerbitan, kemudian tekan **Save**.
4. Pastikan `index.html`, `assets/`, `css/`, `js/` dan folder `pages/` berada pada akar sumber penerbitan. Kekalkan struktur folder selepas mengekstrak ZIP.

Semua data latihan ialah sintetik, bukan rekod atau statistik rasmi UTM. Dokumen rasmi yang digunakan dalam latihan dipautkan terus daripada laman asal UTM.

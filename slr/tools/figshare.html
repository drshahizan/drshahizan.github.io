RESEARCH DATA · STAGE 4 · SHARE SLR DATA

figshare

A repository for datasets, figures and other research outputs, with DOIs for published items and private links that can be shared with reviewers before publication.

Purpose: Data Repository with DOIStage fit: Stage 4Relevance: Core / useful

How it can support an SLR

An alternative to Zenodo for depositing the SLR dataset (search strings, screening log, extraction and quality assessment files). Some publishers integrate figshare for supplementary material, so check whether your target journal does.

Key facts (checked 18 November 2026)

  • Free accounts include 20 GB of private storage, with files up to 20 GB.
  • Items can be shared through a private link for blind peer review and embargoed until publication.
  • Your university may have an institutional figshare with different limits.

Step-by-step

  1. Create an item, choose the type Dataset, and upload the files with a README.
  2. Add authors, keywords, description, licence and funding.
  3. Generate a private link for reviewers if the journal asks to see the data during review.
  4. Publish (or set an embargo) and use the DOI in the data availability statement.

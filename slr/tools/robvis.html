PAPER VISUALISATION · STAGE 2–3 · QUALITY / RISK-OF-BIAS FIGURES

robvis

An R package and Shiny web app (McGuinness & Higgins, 2021) that turns a risk-of-bias assessment table into publication-quality traffic-light plots (each study × each domain) and summary bar plots.

Purpose: Risk-of-Bias PlotsStage fit: Stage 2, Stage 3Relevance: Core / useful

How it can support an SLR

Use robvis to present your quality assessment results visually in the Results section or a supplementary file. Templates follow established tools: ROB2, ROBINS-I, QUADAS-2 and ROB1 (the flexible template with your own domain names). The development version on GitHub adds ROBINS-E, QUIPS and a Generic template.

Before you start: match your QA tool

  • If you used a named risk-of-bias tool (e.g. ROB2, QUADAS-2), use its template so domain names and judgements are correct.
  • Many computing SLRs use a custom quality checklist (e.g. Yes / Partly / No per question). Use the flexible template (Generic, or ROB1 in the CRAN version), and label the figure “quality assessment”, not “risk of bias”, unless that is what you assessed.
  • Do not convert numeric quality scores into “low / high risk” after the fact unless your protocol defined that mapping.

Step-by-step (web app, no R needed)

  1. Prepare a CSV: column 1 = study ID; one column per domain or QA question; then an Overall column; then a Weight column (use 1 for every study if you are not weighting).
  2. Use the judgement words the template expects (e.g. Low / Some concerns / High for ROB2). The flexible template lets you name the domains.
  3. Open the web app from the robvis GitHub page, upload the CSV, choose the template and the plot type (traffic light or summary).
  4. Choose the colour-blind palette, check the study IDs match your characteristics table, and download PNG or PDF.

R users: install the development version with devtools::install_github("mcguinlu/robvis"), list templates with rob_tools(), then use rob_traffic_light(data, tool = "Generic") and rob_summary(data, tool = "Generic", overall = TRUE).

Cite the tool

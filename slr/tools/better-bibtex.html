Zotero Better BibTeX

A free Zotero plugin that creates stable, customisable citation keys and keeps a BibTeX/BibLaTeX file updated automatically as your Zotero library changes.

Purpose: Zotero Plugin for LaTeXStage fit: Stage 3, Stage 4Relevance: Core / useful

How it can support an SLR

An SLR cites every included study plus background sources, often more than 80 references. Better BibTeX keeps one citation key per study (for example li2024critical) so your LaTeX manuscript, characteristics table and extraction sheet can all use the same identifier.

Compatibility (checked 18 November 2026)

Install the Better BibTeX release that matches your Zotero version. Recent releases no longer support Zotero 7; check the project’s installation page before downloading. Recent Zotero versions also have a native citation-key field, and Better BibTeX works with it.

Step-by-step installation and setup

  1. Download the latest .xpi file from the releases page. Do not unzip it; in Firefox, right-click and choose Save Link As….
  2. In Zotero, open Tools → Plugins (older versions: Add-ons), click the gear icon and choose Install Plugin From File…, then select the .xpi.
  3. Restart Zotero. Better BibTeX settings appear under Settings → Better BibTeX.
  4. Set a citation-key formula your team agrees on, e.g. auth.lower + year + shorttitle(1,0), and keep it for the whole review.
  5. Right-click your SLR collection → Export Collection… → format Better BibTeX (or Better BibLaTeX) → tick Keep updated. This writes a .bib file that updates when you edit the library.
  6. Upload that .bib file to Overleaf (or point your local LaTeX project to it). Re-upload after changes if your Overleaf plan has no reference-manager sync.

Cautions

  • Changing the key formula later changes keys and breaks existing \cite{} commands. Agree on it first.
  • Auto-export covers one collection; put all included studies and background references in it (use sub-collections for organisation).
  • Fix metadata in Zotero (titles, DOIs, capitalisation), not in the exported file, or the next export overwrites your edits.

Zoplicate

A Zotero plugin for detecting and managing duplicate references while retaining useful metadata from the records being merged.

Purpose: Zotero Duplicate ManagementStage fit: Stage 1, Stage 2, Stage 3Relevance: Core / useful

How it can support an SLR

Duplicate references can enter an SLR library when records are imported from several databases. Zoplicate detects likely duplicates during import and helps researchers decide whether to keep the new record, keep the existing record, retain both records, or review the items manually.

The plugin uses Zotero's merge workflow rather than arbitrarily deleting duplicates. Notes, tags, collections and attachments should still be checked after every merge.

Main features

  • Detects likely duplicates when new references are imported.
  • Supports Keep New, Keep Old, Keep All and manual review.
  • Provides bulk merging for duplicate groups.
  • Allows false matches to be marked as non-duplicates.
  • Can display duplicate statistics in the Zotero collection pane.
  • Supports exporting and importing non-duplicate decisions between devices.

Compatibility and download

Check your Zotero version before installation by selecting Help → About Zotero. The current Zoplicate 5 series targets Zotero 9 and Zotero 10. Users of earlier Zotero versions should select a compatible release from the project's release history.

Step-by-step installation

  1. Open the latest release page.
  2. Under Assets, download zoplicate.xpi. Do not extract the file. If Firefox attempts to install it, right-click the link and select Save Link As….
  3. Open Zotero and select Tools → Plugins. In some older versions, this may appear as Tools → Add-ons.
  4. Click the settings or gear icon at the top of the Plugins window.
  5. Select Install Plugin From File….
  6. Locate and select the downloaded zoplicate.xpi file, then confirm the installation.
  7. Restart Zotero.
  8. Return to Tools → Plugins and confirm that Zoplicate is enabled.

Alternative method: Open the Plugins window and drag the zoplicate.xpi file directly into it.

Recommended initial configuration

Open Edit → Settings → Zoplicate. On macOS, use Zotero → Settings → Zoplicate.

  • Set the duplicate action to Always Ask while learning the workflow.
  • Review the Master Item setting before merging records.
  • Use Earliest Added only if it matches the review team's reference-management policy.
  • Test the configuration with a small, recoverable sample before applying it to the full library.

Using Zoplicate

  1. Import references into Zotero from a database, DOI, RIS file or BibTeX file.
  2. When Zoplicate identifies a likely duplicate, compare the title, authors, year, DOI, publication details, tags, notes and attachments.
  3. Select Keep New, Keep Old, Keep All, or open Duplicate Items for manual review.
  4. Verify the retained record after merging.
  5. Record significant deduplication decisions in the SLR documentation.

Bulk merge: use with care

The Bulk Merge All Duplicate Items command can process many duplicate groups, but it should not be the first action taken on an unreviewed library.

  1. Allow Zotero Sync to finish.
  2. Create a backup of the Zotero data directory.
  3. Check the Master Item preference.
  4. Review several duplicate groups manually.
  5. Run bulk merge only after confirming that the rules produce the intended results.
  6. Inspect notes, tags, collections and attachments after completion.

Important: Deduplication is a review decision. Automation can accelerate the process, but the researcher remains responsible for confirming that two records represent the same study.

Non-duplicate decisions

If two similar records are different publications, mark them as They are NOT duplicates. These decisions are stored locally and do not automatically synchronise through Zotero. To move them to another computer, use Settings → Zoplicate → Data Management → Export Non-Duplicates…, then import the exported file on the other device.

Troubleshooting

  • Plugin is incompatible: install a Zoplicate release that supports your Zotero version.
  • Plugin does not appear: restart Zotero and confirm that it is enabled in the Plugins window.
  • The downloaded file is a ZIP: download the release asset named zoplicate.xpi, not the source-code archive.
  • Unexpected merge result: stop bulk processing, inspect Zotero Trash, and restore items where appropriate.

What to record in your SLR

  • Zotero and Zoplicate versions
  • Date of deduplication
  • Databases or files imported before deduplication
  • Duplicate rule and Master Item preference
  • Number of records before and after deduplication
  • Manual checks, exceptions and restored records

This information supports a transparent PRISMA flow and makes the review process more reproducible.

Stage 2 purpose

Start the shared Stage 2 practice pack →

Stage 2 turns the Stage 1 search results into a documented set of eligible studies and a structured evidence base. Begin with the approved protocol draft, database exports, search log and backup copy of the original records.

✓
Hands-on workbook

Use the Stage 2 Review Workbook for a pilot decision log, count reconciliation, appraisal notes and extraction planning. It saves locally in the current browser.

1. Confirm the protocol and criteria

Check that the review question, eligibility rules, screening steps, quality appraisal approach and extraction fields are clear before full screening. If a rule needs to change, record the version, date and reason, and apply it consistently.

2. Deduplicate and prepare records

  1. Combine exports from every planned source and preserve the original files.
  2. Use DOI and title matching to identify probable duplicates.
  3. Review uncertain matches manually; related reports from one study are not necessarily duplicates.
  4. Record the counts before and after deduplication.

3. Calibrate, screen and resolve disagreements

  1. Have reviewers independently apply the draft criteria to a small shared pilot sample.
  2. Discuss disagreements and clarify ambiguous definitions before screening the remaining records.
  3. Screen titles and abstracts, retaining an uncertain option where the abstract is insufficient.
  4. Retrieve potentially eligible full texts and record a primary reason for each full-text exclusion.
  5. Document conflicts, resolution and reviewer roles in the review system or decision log.

Tool guides are separate so participants can learn setup without crowding the review record: Gemini Notebook document-analysis guide; also see Zotero, Rayyan, and optional Covidence.

4. Reconcile the selection flow

Check the number of identified records, duplicates removed, records screened, reports sought and assessed, full-text exclusions and included studies against the source records. The PRISMA 2020 flow diagram page provides flow templates for documenting selection and exclusion reasons. PRISMA is a reporting guideline; it does not replace the review protocol.

5. Appraise study quality

Select appraisal criteria that fit the review question and included study designs. Define how judgements will be recorded, pilot the checklist and retain supporting evidence and rationale. Avoid applying a health-specific risk-of-bias instrument by default to computing or software engineering evidence.

6. Pilot extraction and prepare synthesis

Build extraction fields from the research questions. Typical fields include study identity, context, aim, design, sample or dataset, method, evaluation measures, findings, limitations and page-level evidence. Pilot the form on varied studies, refine unclear fields, then extract consistently. Group findings by research question, method, context or theme before drafting conclusions.

Hands-on practice files

The shared practice set uses 23 clearly labelled synthetic records so participants can practise deduplication, calibration, abstract screening and full-text decisions before using their own records. Open participant instructions.

Tool guides

Reporting and appraisal references

Use the PRISMA 2020 flow diagram guidance to report the selection process. PRISMA is a reporting guideline and does not replace the review protocol. Choose appraisal criteria that fit the review question and included study designs.

Hands-on practice files

The shared practice set uses 23 clearly labelled synthetic records so participants can practise deduplication, calibration, abstract screening and full-text decisions before using their own records. Open participant instructions.

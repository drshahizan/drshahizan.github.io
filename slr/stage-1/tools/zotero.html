Zotero

Use Zotero to collect and organize scholarly references discovered during your review. Zotero is a reference manager, rather than a literature-discovery or screening database. Set it up early, then use it to keep verified records organized as your search develops.

01 · Install and sign in

Set up Zotero Desktop and Connector

  1. Download and install Zotero Desktop from the official Zotero website.
  2. Install Zotero Connector for your browser. It adds a save button for capturing references from compatible web pages.
  3. Create a Zotero account at zotero.org if you want to sync your library between computers. Sign in to that account in Zotero’s Sync settings.
  4. Open Zotero Desktop before saving records so the Connector can send them to your local library. Check the selected collection in the save window.

You can build a local library without setting up syncing. An account is used for Zotero’s online services and synchronization; file-storage limits may apply to synced attachments.

02 · Use it for SLR

Features that help organize review records

Collections and subcollections

Group records by review topic or work phase while retaining one library.

Browser Connector

Capture bibliographic metadata from database and publisher pages, then check the saved item.

Tags, notes and attachments

Organize records and keep brief working notes with the relevant reference.

Word processor integration

Insert citations and generate a bibliography in supported word processors.

Keep the evidence trail. Export and retain the original RIS/BibTeX search files, and document each formal search in the Stage 1 Search Log. Zotero helps manage references; it is not a replacement for a reproducible search log or a dedicated screening workflow.

03 · Hands-on exercise

Create a review collection and save verified papers

  1. In Zotero Desktop, create a collection named SLR – [short topic].
  2. Open a verified seed article from Scopus, Web of Science or its publisher page. Make sure the page represents the article record, not only a general search-results page.
  3. Use the Zotero Connector button and choose the SLR collection. If prompted, select the article record from the save list.
  4. In Zotero Desktop, inspect the saved title, authors, year, journal and DOI. Correct incomplete metadata using the verified source record.
  5. Repeat for two more relevant seed articles. Add a simple tag such as seed and attach PDFs only where you have lawful access.
  6. Open the Duplicate Items view and inspect any suggested matches. Merge only records you have checked. Zotero’s matching is a useful aid, not a complete systematic deduplication process.
  7. When formal database searches are conducted, import their RIS/BibTeX exports into a clearly named collection and keep the original exports and search log separately.

Quick record-check checklist

✓ Exact title matches the publisher or database record.
✓ Authors and publication year are present.
✓ DOI or stable URL resolves to the same article.
✓ Collection and tags make the record easy to find later.

04 · Take the result back

What should go into Topic & Scope?

Keep the Zotero library as your reference-management space. In the Topic & Scope worksheet, record only the exact title and DOI or stable link of one verified seed paper, plus a concise insight that informs your topic.

The Zotero collection is organized, three seed records have been checked, and at least one record’s DOI or stable URL has been verified against its source.

How submissions are assessed

Step 1 · Completeness check

A submission is reviewed only if:

  • all three links open and allow comments,
  • the Excel file lists every included article with quality criteria and a score for each, and
  • the number of included studies is the same in the PRISMA diagram, the Excel file and the draft.

Step 2 · Quality rubric

Each criterion is scored from 1 to 5 and weighted as shown. Swipe the table sideways to see all levels.

CriterionWeight1 · Weak3 · Adequate5 · Excellent
Research questions & scope15%RQs unclear or too broadRQs clear; scope mostly justifiedRQs precise, answerable and well justified
Search & PRISMA25%Sources or search strings missing; counts do not reconcileSources and strings reported; minor gapsFully reproducible search; complete, consistent PRISMA flow
Quality assessment25%No or unclear criteriaRecognised criteria applied to most articlesAppropriate criteria applied consistently, with justified decisions
Draft quality20%Outline onlyIntroduction and method draftedFull draft with early synthesis, clearly written
Publication potential15%Contribution unclearSome contribution; journal fit uncertainClear, novel contribution with a suitable target journal

Selection is made by the secretariat based on this rubric. Scores and individual feedback will not be released.

How to get a shareable link
  1. Google Drive: upload the file › right-click › Share › add the reviewer email below as Commenter (or set General access to “Anyone with the link · Commenter”) › Copy link.
  2. OneDrive / SharePoint (UTM Microsoft 365): open the file › Share › allow the reviewer to view or comment › Copy link.
  3. Name files clearly, for example MatricNo_Name_SLR_Draft_v1.docx, MatricNo_QA.xlsx, MatricNo_PRISMA.pdf.

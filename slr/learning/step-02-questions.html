Step 02 of 10

Formulate Research Questions

Create precise questions that determine what evidence must be searched, extracted, and synthesised.

Select a suitable framework

PICO / PICOCPopulation, intervention, comparison, outcome, context
SPIDERSample, phenomenon, design, evaluation, research type
PCCPopulation, concept, context
CIMOContext, intervention, mechanism, outcome

Complete these tasks

  1. Select the framework that matches your discipline and evidence.
  2. Map the topic into the framework components.
  3. Draft two to four research questions.
  4. Check that every question is answerable using extractable data.
  5. Align every question with an intended analysis or table.
Useful question patterns

What methods have been used? What factors influence the outcome? How does performance differ? What limitations and research gaps remain?

Quality check

  • Questions are specific and non-overlapping.
  • They collectively address the review purpose.
  • They avoid yes/no answers.
  • Each question has identifiable data fields.

Required output

Research Question Table

  • Selected framework
  • Framework components
  • RQ1–RQ4
  • Purpose of each RQ
  • Required evidence

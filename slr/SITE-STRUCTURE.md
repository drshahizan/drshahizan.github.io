# SLR Course Portal 2026

## HTML structure

- `index.html` — Home
- `programme/index.html` — Programme overview and dates
- `stages/stage-1.html` — Discover
- `stages/stage-2.html` — Review
- `stages/stage-3.html` — Write
- `stages/stage-4.html` — Refine
- `stage-1/` — seven guided Stage 1 steps; `search-strings.html` combines the keyword matrix, Gemini term-suggestion prompt builder and Boolean search-string builder, while `keywords.html` redirects for compatibility; `topic.html` is the output worksheet, `topic-tools.html` is the tool directory, and `tools/` contains one hands-on guide per database, platform or tool (Gemini, Scopus, Scopus AI, Web of Science Core Collection, IEEE Xplore, ScienceDirect, Springer Nature Link, Publish or Perish, ResearchRabbit, Zotero)
- `workspace/` — article dashboard, registration, duplicate detection and study management
- `learning/` — detailed 10-step SLR learning materials
- `tools.html` — searchable, locally hosted cross-stage directory of 84 SLR-support tools
- `tools/` — dedicated SLR learning page for each catalogued tool; links to the existing Stage 1 guides resolve within this site
- `resources/index.html` — templates, materials and additional resources
- `assets/` — shared CSS, JavaScript and CSV templates, including the search/filter catalogue and tool-guide styles and data

The 2024 SLR-FC GitHub materials are retained as legacy references and linked from the relevant 2026 stage pages.

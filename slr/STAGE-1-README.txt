SLR Stage 1 guided workspace

This ZIP is the full SLR website. Extract all files into the repository root, not inside another slr folder.
Open stages/stage-1.html or stage-1/topic.html. The separate tool directory is stage-1/topic-tools.html. Individual hands-on guides are in stage-1/tools/. Each guide covers access, SLR-relevant search features, a hands-on exercise and what to record. Search logs belong in the Search Log worksheet; organize exported references in Zotero.
Stage 1 responses are saved to the participant browser localStorage only; export portfolio as Markdown or JSON backup. No Google Sheets integration has been added.
The Zotero guide is stage-1/tools/zotero.html. Use Zotero to organize verified references, but retain original database exports and document formal searches separately.
The initial article register is a lightweight sample; participants should retain full CSV/RIS/BibTeX exports separately.

The keyword matrix and Boolean search builder are combined in stage-1/search-strings.html. The former stage-1/keywords.html URL redirects to this workspace for compatibility. The optional Gemini prompt builder suggests candidate terms; participants select and verify terms before generating a Boolean string.

New Stage 1 practice pages:
- stage-1/search-readiness.html: locally saved search-quality checklist and print view.
- stage-1/database-coverage.html: locally saved database/source coverage matrix with CSV export and print view.
The learning-resources page now includes the PRESS checklist and university library video tutorials.

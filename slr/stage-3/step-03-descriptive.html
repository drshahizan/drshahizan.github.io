Key guidance

  • Typical descriptive results: publications per year, publication type and venue, country or region, research design, application domain, datasets, techniques and evaluation measures.
  • Generate counts with a pivot table or script from the coding sheet. Keep the file so reviewers can reproduce every number.
  • Use bibliometric maps (co-occurrence of keywords, co-authorship) only if they answer an RQ. Always state the software, version, thresholds and data source.
  • Report percentages with the denominator (e.g. “18 of 42 studies, 43%”).
  • Describe what the patterns mean for the evidence, e.g. “most studies were single-site pilots”, rather than listing numbers only.
Needs revision

Weak: “Figure 3 shows the number of publications per year.”

Stronger

Strong: “Publications increased sharply after 2022 (31 of 42 studies, 74%), coinciding with public release of large language models; only 4 studies predate 2020.”

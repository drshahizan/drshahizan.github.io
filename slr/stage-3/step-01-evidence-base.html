Key guidance

  • Start from the outputs you exported at the end of Stage 2: included-study list, PRISMA counts, appraisal results and the extraction matrix.
  • Check that the number of rows in the matrix equals the number of included studies in the PRISMA diagram. Resolve any mismatch before analysis.
  • Add study-level coding columns you will need for description and grouping: year, country/region, setting, design, sample, intervention/technology, outcome type.
  • Use controlled values (e.g. a fixed list of design labels) so the data can be counted and charted without manual clean-up.
  • Verify a sample (e.g. 10–20%) of extracted entries against the full texts, or ask a co-author to do so, and record the result.
Needs revision

Weak: “Design” column contains “survey”, “questionnaire study”, “Survey-based”, “quant”.

Stronger

Strong: “Design” uses one controlled list — Experimental · Quasi-experimental · Survey · Case study · Qualitative · Mixed methods · Design science — with a codebook definition for each.

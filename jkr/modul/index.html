6 modul bersepadu

Modul pembelajaran

Ikuti turutan daripada perancangan sehingga penerbitan. Setiap modul mengandungi hasil, aktiviti amali dan semakan kendiri.

01 · Asas02 · Perancangan03 · Prompt04 · Pembangunan05 · Kualiti06 · Penerbitan
Modul 01

AI dalam tugasan pembangunan web

Fahami peranan AI sebagai pembantu analisis, penjana kod, penyemak dan dokumentasi—bukan pengganti pertimbangan pegawai.

  • Kenal pasti tugas yang sesuai dibantu AI
  • Fahami risiko ketepatan, privasi dan hak cipta
  • Gunakan kaedah semak–uji–sahkan
Modul 02

Perancangan laman dan pengalaman pengguna

Bentuk objektif, profil pengguna, peta laman, kandungan dan aliran utama sebelum menghasilkan kod.

  • Tulis pernyataan masalah dan hasil laman
  • Bina persona ringkas serta senario penggunaan
  • Susun menu dan halaman mengikut keutamaan
Modul 03

Prompt untuk pembangunan web

Gunakan kerangka Peranan–Konteks–Tugas–Keperluan–Kekangan–Output untuk mendapatkan hasil yang konsisten.

  • Prompt induk projek
  • Prompt reka bentuk dan kandungan
  • Prompt pembaikan ralat dan semakan kod
Modul 04

HTML, CSS dan JavaScript

Pelajari struktur asas tiga teknologi web dan cara membaca serta mengubah kod yang dijana AI.

  • HTML semantik dan struktur halaman
  • CSS responsif, warna dan tipografi
  • JavaScript untuk menu, penapis dan borang
Modul 05

Ujian, keselamatan dan kebolehcapaian

Semak laman pada pelbagai skrin, uji semua pautan dan pastikan kandungan jelas serta boleh digunakan.

  • Ujian desktop dan telefon
  • Label borang, kontras dan navigasi papan kekunci
  • Elakkan data peribadi dan maklumat sulit dalam kod
Modul 06

GitHub dan GitHub Pages

Urus fail projek, rekod perubahan dan terbitkan laman rasmi menggunakan proses yang boleh diulang.

  • Cipta repositori dan struktur fail
  • Muat naik atau commit perubahan
  • Aktifkan Pages dan sahkan URL penerbitan

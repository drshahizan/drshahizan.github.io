Terbitkan website dengan GitHub

Terbitkan kali pertama melalui pelayar dan gunakan GitHub Desktop untuk kemas kini seterusnya—tanpa Terminal atau arahan Git.

Hasil pembelajaran

Persediaan

Kenal repository, struktur fail dan kedudukan index.html.

Penerbitan

Muat naik fail dan aktifkan GitHub Pages menggunakan branch main.

Kemas kini

Clone, commit dan push perubahan melalui GitHub Desktop.

1Ekstrak ZIP
2Cipta repository
3Muat naik fail
4Aktifkan Pages
5Buka URL
6Kemas kini
Peraturan utama: Jangan muat naik ZIP secara terus. Ekstrak ZIP dan muat naik kandungannya. Fail index.html mesti berada pada aras utama repository.
A1

Sediakan fail website

  1. Muat turun ZIP projek.
  2. Pilih Extract All atau Unzip.
  3. Buka folder yang diekstrak.
  4. Pastikan terdapat index.html, folder css dan js.
✓ Betul
index.html
css/
js/
README.md
✕ Salah
nama-projek/
└── nama-projek/
    └── index.html
A2

Cipta repository baharu

GitHub.com›+›New repository
  1. Masukkan nama seperti projek-aduan-jkr.
  2. Pilih Public.
  3. Aktifkan Add a README file.
  4. Klik Create repository.
Jangan masukkan: kata laluan sebenar, nombor kad pengenalan, data peserta, laporan sulit atau API key.
A3

Muat naik kandungan

Add file›Upload files›Pilih semua kandungan
  1. Pilih semua fail dan folder dalam folder projek.
  2. Seret fail ke GitHub dan tunggu selesai.
  3. Tulis Muat naik versi pertama website.
  4. Klik Commit changes.
Semak bahawa index.html, css dan js kelihatan pada halaman utama repository.
A4

Aktifkan GitHub Pages

Settings›Pages›Deploy from a branch›main›/(root)›Save

Tunggu beberapa minit dan kembali ke halaman Pages untuk URL.

https://NAMA-PENGGUNA.github.io/NAMA-REPOSITORY/
A5

Uji website

Istilah asas GitHub Desktop

CloneSalin repository ke komputer.
ChangesFail yang ditambah atau diubah.
CommitSimpan rekod perubahan.
Push originHantar perubahan ke GitHub.
Fetch originSemak versi terkini.
mainBranch utama website.
B1

Pasang dan log masuk

  1. Muat turun dari desktop.github.com.
  2. Pasang dan buka aplikasi.
  3. Klik Sign in to GitHub.com.
  4. Gunakan akaun GitHub yang sama.
B2

Clone repository

Repository di GitHub›Code›Open with GitHub Desktop›Local Path›Clone
Documents/GitHub/projek-aduan-jkr
Gunakan Repository → Show in Explorer/Finder untuk membuka folder projek yang betul.
B3

Masukkan atau ubah fail

  1. Buka folder repository melalui GitHub Desktop.
  2. Salin kandungan projek ke folder tersebut.
  3. Jangan padam folder tersembunyi .git.
  4. Kembali ke GitHub Desktop dan semak Changes.
B4

Commit dan Push Origin

Edit›Changes›Summary›Commit to main›Push origin
  1. Semak perubahan dan isi Summary seperti Kemas kini halaman utama.
  2. Klik Commit to main.
  3. Klik Push origin.
  4. Tunggu GitHub Pages menerbitkan perubahan.
Commit menyimpan rekod dalam komputer. Website hanya menerima perubahan selepas Push origin.
B5

Kitaran kemas kini

  1. Pilih repository dan branch main.
  2. Klik Fetch origin.
  3. Edit atau gantikan fail.
  4. Semak Changes.
  5. Commit to main.
  6. Push origin.
  7. Uji URL GitHub Pages.
Jangan gunakan Discard Changes jika tidak pasti kerana ia boleh membuang perubahan dalam komputer.

Prompt bantuan peserta

Anda ialah pembimbing GitHub untuk peserta bukan IT. Saya menggunakan [PELAYAR WEB / GITHUB DESKTOP] dan tidak mahu menggunakan Terminal atau arahan Git.

Keadaan semasa saya:
[TERANGKAN APA YANG DIPAPARKAN]

Tindakan yang saya mahu lakukan:
[MUAT NAIK / AKTIFKAN PAGES / CLONE / COMMIT / PUSH / BAIKI RALAT]

Bimbing saya satu langkah pada satu masa menggunakan nama menu dan butang sebenar. Sebelum setiap tindakan, terangkan fungsi tindakan, apa yang akan berubah dan sama ada ia boleh membuang fail. Gunakan Bahasa Melayu mudah. Jangan gunakan force push, reset, rebase atau command line.

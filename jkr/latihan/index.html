Latihan amali

Lapan tugasan kecil membentuk satu laman web lengkap. Simpan setiap hasil kerana semuanya digunakan dalam projek akhir.

Kaedah kerja: cuba sendiri → minta bantuan AI → semak perubahan → uji dalam pelayar → catat penambahbaikan.
01

Takrif masalah

Tulis tujuan, sasaran pengguna, tiga tugas utama dan ukuran kejayaan laman.

20 minit
02

Peta laman

Hasilkan menu dan hubungan antara halaman utama, maklumat serta tindakan pengguna.

25 minit
03

Prompt induk

Bina arahan projek lengkap merangkumi kandungan, identiti visual dan kekangan teknikal.

30 minit
04

Halaman utama

Jana index.html dengan navigasi, hero, kandungan utama, tindakan dan footer.

45 minit
05

Gaya responsif

Bina CSS untuk desktop dan telefon dengan hierarki, jarak serta warna konsisten.

40 minit
06

Interaksi

Tambah menu mudah alih, carian atau penapis dan pengesahan borang asas.

45 minit
07

Audit kualiti

Gunakan senarai semak untuk membaiki pautan, ejaan, kontras dan paparan skrin.

30 minit
08

Terbitkan

Muat naik fail ke GitHub, aktifkan GitHub Pages dan kongsi URL hasil akhir.

30 minit

Sambungkan website kepada Google Sheets

Ikuti langkah mengikut urutan. Anda hanya perlu menyalin fail, menampal kod dan menukar satu URL.

1Sediakan Google Sheets

  1. Buka Google Drive.
  2. Klik New > File upload.
  3. Pilih dokumen/Pangkalan_Data_Portal_Aduan_JalanCare.xlsx.
  4. Selepas muat naik, klik kanan fail dan pilih Open with > Google Sheets.
  5. Pilih File > Save as Google Sheets.

Penting: Jangan ubah nama tab seperti ADUAN, PENGGUNA, SESI dan LOG_AKTIVITI. Kod menggunakan nama ini.

2Masukkan Google Apps Script

  1. Dalam Google Sheets, pilih Extensions > Apps Script.
  2. Di sebelah kiri, buka Code.gs.
  3. Padam kod contoh.
  4. Buka fail google-apps-script/Code.gs daripada pakej ini.
  5. Salin semua kod, tampal ke editor Apps Script dan klik ikon Save.

3Terbitkan sebagai Web App

  1. Klik Deploy > New deployment.
  2. Klik ikon gear dan pilih Web app.
  3. Description: JalanCare API v1.
  4. Execute as: Me.
  5. Who has access: Anyone.
  6. Klik Deploy dan beri kebenaran yang diminta.
  7. Salin Web app URL yang berakhir dengan /exec.

Jika Google memaparkan “This app isn't verified”, pilih Advanced, kemudian teruskan ke projek anda. Ini berlaku kerana skrip itu milik akaun anda sendiri.

4Uji API

Buka URL berikut dalam pelayar. Gantikan bahagian pertama dengan URL Web App anda:

https://script.google.com/macros/s/ID_ANDA/exec?action=ping

Jika berjaya, skrin memaparkan respons yang mengandungi "ok":true dan JalanCare API aktif.

5Sambungkan website

  1. Buka fail js/config.js menggunakan Notepad atau VS Code.
  2. Cari teks MASUKKAN_URL_GOOGLE_APPS_SCRIPT_WEB_APP.
  3. Gantikan teks itu dengan URL /exec daripada Langkah 3.
  4. Simpan fail.
window.JALANCARE_CONFIG = { API_URL: "https://script.google.com/macros/s/ID_ANDA/exec", REQUEST_TIMEOUT_MS: 20000 };

6Uji fungsi utama

  1. Buka website melalui pelayan web atau GitHub Pages.
  2. Hantar satu aduan melalui Buat Aduan.
  3. Salin nombor rujukan dan kod empat digit.
  4. Gunakan Semak Status.
  5. Log masuk sebagai admin / Admin@123.
  6. Semak dashboard, senarai aduan dan butiran aduan.
  7. Kemas kini status; pastikan tab ADUAN, TINDAKAN dan LOG_AKTIVITI berubah.

7Terbitkan di GitHub Pages

  1. Ekstrak folder projek.
  2. Buka GitHub Desktop dan pilih File > New repository.
  3. Nama repositori: projek1-db. Pilih folder projek sebagai Local path.
  4. Klik Create repository.
  5. Masukkan ringkasan Projek 1 DB JalanCare, kemudian klik Commit to main.
  6. Klik Publish repository dan pastikan pilihan private tidak ditanda jika menggunakan GitHub Pages percuma.
  7. Di github.com, buka repositori > Settings > Pages.
  8. Source: Deploy from a branch; Branch: main; Folder: /(root); klik Save.
  9. Tunggu beberapa minit dan buka URL yang diberi oleh GitHub Pages.

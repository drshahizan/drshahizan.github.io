# Kursus Alat Digital dan Analisis Penyelidikan

Laman statik mobile-first untuk GitHub Pages.

## Cara menerbitkan

1. Ekstrak fail ZIP.
2. Muat naik semua kandungan folder ini ke repositori GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, cabang `main`, folder `/ (root)`.
5. Simpan dan tunggu pautan GitHub Pages tersedia.

## Mengemas kini laman

- Maklumat utama: `index.html`
- Jadual: `tentatif.html`
- Pusat modul: `modul/index.html`
- Nota setiap modul: `modul/modul-1-ekosistem-digital.html` hingga `modul/modul-7-ai-penyelidikan.html`
- Latihan mengikut modul: folder `latihan/`
- Katalog dan panduan alat: folder `alatan/`
- FAQ, glosari dan panduan pantas: folder `sumber/`
- Warna dan paparan: `css/style.css`
- Fail kursus: folder `assets/`

## Nota

Tentatif dan status akses alat perlu disahkan sebelum kursus. Kemajuan latihan disimpan pada pelayar pengguna dan tidak dihantar ke pelayan.

Visitor badge dipaparkan secara automatik pada footer semua halaman melalui `js/script.js`.
Header, dropdown Modul/Alatan/Latihan/Sumber dan breadcrumb dikendalikan melalui `js/navigation.js`.

## Panduan alat individu

- `alatan/modul-2/alat-google-scholar.html`
- `alatan/modul-2/alat-zotero.html`
- `alatan/modul-2/publish-or-perish/index.html`
- `alatan/modul-2/alat-mendeley.html`
- `alatan/modul-2/alat-endnote.html`
- `alatan/modul-3/scopus-ai/index.html`

Panduan individu disusun mengikut folder modul. Alat yang mempunyai banyak bahagian menggunakan subfolder sendiri, contohnya `publish-or-perish/`, `scopus-ai/` dan `gemini-notebook/`.

## Sokongan peserta

- `mula-di-sini.html`: persediaan dan laluan hari bengkel
- `sumber/panduan-pantas.html`: urutan tindakan alat utama
- `sumber/faq.html`: penyelesaian masalah dan soalan lazim
- `sumber/glosari.html`: definisi istilah asas
- `assets/datasets/latihan/`: bahan latihan tambahan
- `assets/datasets/jawapan/`: contoh jawapan

Google Data Studio

Bina dashboard interaktif terus daripada fail CSV dataset Modul 6.

Buka Google Data Studio ↗Ikuti Latihan Dashboard
Nama semasa perkhidmatan: Antara muka rasmi mungkin memaparkan nama Looker Studio. Dalam modul ini, istilah Google Data Studio digunakan mengikut keperluan kursus.

Langkah ringkas

  1. Muat turun CSV Modul 6.
  2. Pilih Create → Data source → File Upload.
  3. Muat naik CSV dan pilih Connect.
  4. Cipta report daripada sumber data.
  5. Tambah scorecard, time series, bar chart dan table.
  6. Tambah date range dan drop-down filter.
  7. Uji paparan View sebelum berkongsi.

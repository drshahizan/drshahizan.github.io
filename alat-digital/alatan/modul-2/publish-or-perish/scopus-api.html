Sambungkan Scopus API

Gunakan API key peribadi dan akses institusi untuk menjalankan carian Scopus dalam PoP.

A · Dapatkan key

Elsevier Developer Portal

  1. Log masuk ke portal pembangun Elsevier.
  2. Pilih I want an API Key.
  3. Daftarkan aplikasi, contohnya “Publish or Perish UTM”.
  4. Nyatakan penggunaan akademik bukan komersial.
  5. Salin API key yang diberikan.
Buka Portal Elsevier ↗
B · Masukkan ke PoP

Tools → Preferences

  1. Buka Tools → Preferences.
  2. Pilih tab Scopus.
  3. Tampal key dalam ruangan API key.
  4. Simpan dan kekalkan tetapan lain pada nilai asal.
  5. Pilih carian Scopus dan jalankan ujian kecil.
Penyelesaian masalah

Jika carian tidak berjaya

Invalid API key

Salin semula key dan pastikan tiada ruang kosong tambahan.

Insufficient privileges

Gunakan rangkaian, VPN atau kaedah akses institusi yang sah. Akses penuh bergantung pada langganan institusi.

429 Too Many Requests

Hentikan permintaan dan tunggu kuota atau had kadar dipulihkan. Jangan gunakan Search Direct berulang kali.

Hasil tidak lengkap

Semak parameter, had hasil, jenis akses dan sumber Scopus asal.

Keselamatan: API key ialah kelayakan peribadi. Jangan letakkannya dalam GitHub, slaid, borang atau tangkap layar.

Panduan alternatif · Modul 2

EndNote

Pengurus rujukan berlesen untuk membina pustaka, mengimport rekod dan menghasilkan sitasi melalui Cite While You Write.

Buka EndNote ↗Kembali ke Modul 2

Sebelum memasang

Semak sama ada lesen disediakan oleh UTM atau komputer makmal. Jangan membeli lesen hanya untuk kursus sehari.

Komponen penting

EndNote Desktop, fail library, folder data berkaitan dan add-in Word Cite While You Write.

Pemasangan

Sediakan EndNote

  1. Dapatkan installer rasmi atau installer institusi yang sah.
  2. Tutup Microsoft Word sebelum menjalankan pemasangan.
  3. Jalankan installer dan pastikan Cite While You Write dipilih.
  4. Buka EndNote dan cipta library baharu melalui File → New.
  5. Buka semula Word dan semak tab EndNote pada ribbon.
  6. Simpan fail library dan folder data berkaitan bersama-sama.
Penggunaan asas

Import dan gunakan rujukan

  1. Eksport rekod daripada pangkalan data menggunakan format yang sesuai.
  2. Dalam EndNote, pilih File → Import dan pilih penapis import yang sepadan.
  3. Semak metadata dan kumpulkan rujukan ke dalam Group.
  4. Dalam Word, pilih tab EndNote dan klik Insert Citation.
  5. Cari pengarang atau tajuk, kemudian masukkan sitasi.
  6. Pilih gaya output; bibliografi akan dikemas kini secara automatik.

Jika tab EndNote tiada: Semak pemasangan Cite While You Write, tutup Word dan jalankan pembaikan pemasangan jika diperlukan.

Hasil demonstrasi: Satu library, satu rekod import, satu sitasi dan satu bibliografi.

Panduan alternatif · Modul 2

Mendeley Reference Manager

Alternatif kepada Zotero untuk mengurus rujukan, membaca PDF dan memasukkan sitasi melalui Mendeley Cite.

Muat Turun Mendeley ↗Kembali ke Modul 2
Komponen

Apa yang digunakan?

Reference Manager

Mengurus pustaka, koleksi, metadata, PDF dan anotasi.

Web Importer

Menyimpan rujukan daripada laman web ke pustaka Mendeley.

Mendeley Cite

Add-in Word untuk sitasi dan bibliografi.

Pemasangan

Sediakan Mendeley

  1. Cipta akaun Mendeley atau Elsevier.
  2. Muat turun Mendeley Reference Manager mengikut sistem operasi.
  3. Pasang aplikasi, buka dan log masuk untuk menyegerakkan pustaka.
  4. Pasang Web Importer pada pelayar jika mahu menyimpan dari web.
  5. Dalam Word, buka Insert → Get Add-ins dan cari Mendeley Cite.
  6. Tambah Mendeley Cite dan log masuk menggunakan akaun yang sama.
Demonstrasi ringkas

Import, susun dan cite

  1. Import satu atau beberapa fail PDF.
  2. Semak tajuk, pengarang, tahun, jurnal dan DOI.
  3. Tambahkan artikel ke dalam koleksi dan letakkan tag.
  4. Buka PDF untuk highlight, anotasi atau nota.
  5. Buka Mendeley Cite dalam Word, pilih artikel dan masukkan sitasi.
  6. Pilih gaya dan bina bibliografi.

Cadangan kursus: Gunakan Zotero sebagai alat hands-on utama. Mendeley ditunjukkan untuk membantu peserta memahami pilihan alternatif, bukan untuk mengulangi keseluruhan latihan.

Hasil demonstrasi: Satu rekod, satu anotasi, satu sitasi dan satu bibliografi.

Bina Dashboard Google Data Studio

Gabungkan metrik, trend, perbandingan dan penapis dalam satu dashboard.

Muat Turun CSVBuka Google Data Studio ↗
Dataset siap guna: Import fail CSV terus ke alat. Jangan ubah atau bersihkan data untuk latihan ini.

A · Sambungkan fail CSV

  1. Buka Google Data Studio dan log masuk dengan akaun Google.
  2. Pilih Create → Data source.
  3. Pilih penyambung File Upload.
  4. Muat naik dataset-visualisasi-perpustakaan.csv.
  5. Pilih Connect.
  6. Semak date sebagai Date; medan kiraan sebagai Number; dan skor sebagai Decimal Number.
  7. Pilih Create report, kemudian sahkan penambahan sumber data.

B · Tambah empat scorecard

  1. Pilih Add a chart → Scorecard.
  2. Gunakan usage_count dengan agregasi Sum.
  3. Salin scorecard tiga kali.
  4. Tukar metrik kepada digital_downloads (Sum), satisfaction_score (Average) dan avg_response_minutes (Average).
  5. Namakan kad: Jumlah Penggunaan, Muat Turun, Purata Kepuasan dan Purata Masa Respons.

C · Bina tiga carta

  1. Tambah Time series: Dimension = date; Metric = Sum usage_count.
  2. Tambah Bar chart: Dimension = service; Metric = Sum usage_count; susun menurun.
  3. Tambah Table: Dimension = faculty; Metrics = Sum usage_count dan Average satisfaction_score.
  4. Tambah tajuk ringkas di atas setiap carta.

D · Tambah interaksi

  1. Tambah Date range control.
  2. Tambah Drop-down list untuk service.
  3. Tambah satu lagi drop-down untuk user_group.
  4. Uji pilihan 2024 sahaja dan satu perkhidmatan.
  5. Pilih Reset untuk kembali kepada semua data.

E · Perkemas dan uji

  1. Susun scorecard pada baris pertama, visual pada baris kedua dan jadual di bawah.
  2. Gunakan palet warna yang konsisten.
  3. Tambah tajuk Dashboard Prestasi Perkhidmatan Perpustakaan.
  4. Tambah teks sumber dan tarikh liputan data.
  5. Buka View dan uji semua penapis.
  6. Jika berkongsi, semak tetapan akses sebelum menyalin pautan.

Hasil: Satu dashboard interaktif dengan empat scorecard, tiga visual dan tiga kawalan.

Bina Dashboard Power BI

Gunakan dataset CSV yang sama untuk membina ukuran DAX, visual dan slicer interaktif.

Muat Turun CSVBuka Power BI ↗

A · Import dataset

  1. Buka Power BI Desktop.
  2. Pilih Home → Get data → Text/CSV.
  3. Pilih dataset-visualisasi-perpustakaan.csv.
  4. Semak pratonton 180 rekod, kemudian pilih Load.
  5. Namakan jadual sebagai LibraryServices.
  6. Dalam Model view, pastikan date ialah Date dan medan angka ialah Whole number atau Decimal number.

B · Bina ukuran DAX

  1. Pilih Modeling → New measure.
  2. Masukkan Total Usage = SUM(LibraryServices[usage_count]).
  3. Tambah Total Downloads = SUM(LibraryServices[digital_downloads]).
  4. Tambah Average Satisfaction = AVERAGE(LibraryServices[satisfaction_score]).
  5. Tambah Average Response = AVERAGE(LibraryServices[avg_response_minutes]).
  6. Format dua ukuran purata kepada dua tempat perpuluhan.

C · Bina dashboard satu halaman

  1. Tambah empat Card menggunakan empat ukuran DAX.
  2. Tambah Clustered bar chart: Y-axis = service; X-axis = Total Usage.
  3. Tambah Line chart: X-axis = date; Y-axis = Total Usage; Legend = service.
  4. Tambah Scatter chart: X-axis = Average Response; Y-axis = Average Satisfaction; Size = Total Usage; Legend = service.
  5. Tambah jadual fakulti dengan penggunaan dan kepuasan.

D · Tambah slicer dan interaksi

  1. Tambah slicer untuk year, service dan user_group.
  2. Pilih satu slicer dan gunakan Format → Edit interactions.
  3. Pastikan slicer menapis semua carta dan kad yang berkaitan.
  4. Uji pilihan tahun 2024 serta satu kumpulan pengguna.
  5. Gunakan ikon pemadam pada slicer untuk mengembalikan semua data.

E · Perkemas dan eksport

  1. Gunakan tajuk Dashboard Prestasi Perkhidmatan Perpustakaan 2023–2025.
  2. Gunakan warna konsisten bagi setiap perkhidmatan.
  3. Paparkan tajuk, unit dan label yang diperlukan.
  4. Tambah nota sumber dataset sintetik Modul 6.
  5. Simpan sebagai dashboard-modul-6.pbix.
  6. Eksport halaman sebagai PDF atau tangkapan imej untuk perbandingan.

Hasil: Satu fail PBIX dengan empat ukuran DAX, empat jenis visual dan tiga slicer.

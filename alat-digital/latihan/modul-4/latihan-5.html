Analisis Pensyarah Universiti Awam

Gunakan penapis yang tepat untuk mengelakkan pengiraan berganda dan hasilkan dashboard enam visual.

Muat Turun CSV ↗Rujuk Latihan Asal ↗

A · Import dan audit

  1. Import CSV dan sahkan lajur negeri, universiti, kewarganegaraan, jantina, tarikh dan staf.
  2. Semak tempoh 2014–2023 dan senarai universiti.
  3. Kira nilai kosong dengan =COUNTBLANK(Julat).
  4. Bina ID rekod menggunakan =TEXTJOIN("|",TRUE,A2:F2).
  5. Tandakan pendua dengan =IF(COUNTIF($G$2:G2,G2)>1,"Semak","Unik").

B · Bina peraturan penapis

AnalisisPenapis wajib
Jumlah nasionalstate=Malaysia, university=All Universities, citizenship=all, sex=both
Jumlah universitistate!=Malaysia, university!=All Universities, citizenship=all, sex=both
Pecahan jantinacitizenship=all, sex=male/female
Pecahan wargacitizenship=citizen/non_citizen, sex=both
Penting: Baris agregat dan baris pecahan tidak boleh dijumlahkan bersama.

C · Analisis trend nasional

  1. Tapis baris jumlah nasional.
  2. Bina Pivot Table: Tahun pada Rows dan jumlah staf pada Values.
  3. Kira perubahan tahunan =B3-B2.
  4. Kira pertumbuhan tahunan =(B3-B2)/B2.
  5. Bina line chart 2014–2023.

D · Analisis jantina dan kewarganegaraan

  1. Bina Pivot Table jantina menggunakan hanya baris male dan female.
  2. Kira peratus wanita: =Staf_Wanita/(Staf_Wanita+Staf_Lelaki).
  3. Bina Pivot Table kewarganegaraan menggunakan citizen dan non_citizen.
  4. Kira peratus bukan warganegara: =Bukan_Warganegara/Jumlah.
  5. Semak bahawa jumlah pecahan sama dengan jumlah yang sepadan.

E · Bandingkan universiti dan UTM

  1. Tapis baris jumlah universiti untuk tahun terkini.
  2. Susun staf daripada terbesar kepada terkecil.
  3. Gunakan =RANK.EQ(B2,$B$2:$B$21,0) untuk kedudukan.
  4. Kira sumbangan UTM: =Staf_UTM/SUM(Julat_Staf_Universiti).
  5. Bandingkan UTM dengan purata menggunakan =AVERAGE(Julat_Staf_Universiti).

F · Dashboard enam visual

  1. Line chart trend nasional.
  2. Stacked bar komposisi jantina.
  3. Bar chart kewarganegaraan.
  4. Horizontal bar sepuluh universiti utama.
  5. Line chart trend UTM.
  6. Kad KPI: jumlah staf, pertumbuhan, peratus wanita dan kedudukan UTM.
  7. Pastikan semua carta menggunakan penapis yang dinyatakan.
Prompt Gemini

Semak analisis lecturers_uni.csv bagi 2014–2023. Gunakan peraturan penapis yang saya berikan dan kesan risiko double counting. Nilai trend nasional, jantina, kewarganegaraan, perbandingan universiti dan UTM. Semak enam visual dashboard. Bagi setiap dapatan, nyatakan penapis, formula, denominator dan bukti. Hasilkan lima dapatan, tiga cadangan dan batasan.

Hasil: Log audit, empat jadual analisis, dashboard enam visual, lima dapatan dan tiga cadangan.

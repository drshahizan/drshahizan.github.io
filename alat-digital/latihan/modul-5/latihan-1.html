Bina Projek dan Import Transkrip

Sediakan projek Taguette dan semak sama ada dokumen latihan diimport dengan betul.

Muat Turun Dataset ZIPBuka Taguette ↗

A · Sediakan dataset

  1. Ekstrak fail ZIP.
  2. Baca README.txt dan metadata-peserta.csv.
  3. Pilih folder transkrip-docx atau transkrip-txt. Jangan gunakan kedua-duanya.
  4. Sahkan terdapat 12 transkrip berlabel P01 hingga P12.

B · Cipta projek

  1. Daftar atau log masuk ke Taguette.
  2. Pilih New Project.
  3. Namakan projek Perkhidmatan Perpustakaan Digital.
  4. Masukkan persoalan kajian: Bagaimanakah pengguna dan pustakawan mengalami, menggunakan dan menilai perkhidmatan perpustakaan digital?
  5. Simpan projek.

C · Import dokumen percubaan

  1. Buka tab Documents dan pilih import dokumen.
  2. Import P01, P05 dan P07.
  3. Tunggu proses penukaran selesai.
  4. Buka setiap dokumen dan semak tajuk, ID peserta, soalan dan jawapan.
  5. Bandingkan dengan fail asal untuk memastikan teks tidak hilang atau bercampur.

D · Import semua transkrip

  1. Jika tiga dokumen percubaan betul, import baki sembilan dokumen.
  2. Semak jumlah dokumen ialah 12.
  3. Pastikan tiada versi berganda.
  4. Catat sebarang masalah import dalam log.

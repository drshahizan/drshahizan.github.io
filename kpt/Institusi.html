Strategi Pemasaran Program

Program Sains Komputer menunjukkan permintaan tinggi. Cadang kempen pemasaran digital untuk menarik lebih ramai pelajar berkemahiran tinggi.

Bimbingan Akademik

Program Kejuruteraan mempunyai kadar pengulangan subjek tertinggi (23%). Cadang program mentor-mentee dan kelas tambahan untuk subjek teras.

Sokongan Kewangan

32% keciciran disebabkan masalah kewangan. Cadang skim bantuan kewangan dan program kerja sambilan untuk pelajar yang memerlukan.

# 🅴 SEKSYEN E — COVER BUKU, LAPORAN & DOKUMEN RASMI

## E1. Template Prompt — Cover Buku Program / Modul Sekolah

```
Anda ialah pentadbir sekolah di Malaysia.

Hasilkan reka bentuk cover buku/modul sekolah beserta cadangan visual.

Maklumat cover:
Tajuk utama        : [Nama program / modul]
Subtajuk           : [Jika ada]
Tahap              : [Sekolah Rendah / Menengah]
Sasaran            : [Guru / Murid]
Tahun              : [Tahun]
Penganjur          : [Sekolah / Unit]

Arahan visual / imej:
- Latar belakang: bangunan sekolah / bilik darjah (imej generik)
- Elemen visual pendidikan (buku, papan putih, komputer)
- Elakkan wajah murid sebenar

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Tajuk jelas dan dominan
- Sesuai untuk cetakan dan PDF
```

## E2. Template Prompt — Cover Laporan Tahunan / Laporan Program

```
Anda ialah pegawai pentadbiran sekolah.

Hasilkan cover laporan rasmi sekolah beserta cadangan visual.

Maklumat cover:
Jenis laporan       : [Laporan Tahunan / Laporan Program]
Nama laporan        : [Tajuk laporan]
Tahun / Tempoh     : [Tahun / Tempoh]
Disediakan oleh     : [Sekolah / Jawatankuasa]

Arahan visual / imej:
- Visual profesional (bangunan sekolah, aktiviti rasmi)
- Elemen grafik minimum dan kemas
- Bendera Malaysia digunakan secara kecil (jika sesuai)

Reka bentuk:
- Gaya formal dan berautoriti
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk kegunaan rasmi PPD/JPN
```

## E3. Template Prompt — Cover Kertas Kerja & Fail Pentadbiran

```
Anda ialah pentadbir sekolah.

Hasilkan reka bentuk cover kertas kerja / fail pentadbiran sekolah.

Maklumat cover:
Tajuk dokumen      : [Nama kertas kerja / fail]
Jenis dokumen      : [Kertas Kerja / Fail Pentadbiran]
Unit bertanggungjawab: [Unit / Panitia]
Tahun              : [Tahun]

Arahan visual / imej:
- Latar minimal (geometri lembut / sekolah)
- Ikon pentadbiran (fail, dokumen, kalendar)
- Elakkan imej berlebihan

Reka bentuk:
- Ringkas dan profesional
- Ikut Standard Grafik Sekolah Malaysia
- Mudah dicetak dan difailkan
```

## E4. Template Prompt — Rekaan Muka Hadapan Buku Teks Tambahan / Modul PdP

```
Anda ialah guru/pentadbir sekolah.

Hasilkan rekaan muka hadapan buku teks tambahan atau modul PdP.

Maklumat modul:
Tajuk modul         : [Nama modul]
Subjek              : [Subjek]
Tahun/Tingkatan     : [Tahun / Tingkatan]
Fokus               : [Topik / Kemahiran]
Pengarang           : [Jika ada]

Arahan visual / imej:
- Visual berkaitan subjek (ikon / ilustrasi pendidikan)

- Elakkan visual terlalu kartun

Reka bentuk:
- Mesra murid dan kemas
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk cetakan dan edaran digital
```



## E5. Template Prompt — Penyeragaman Identiti Visual Dokumen Rasmi Sekolah

```
Anda ialah pentadbir sekolah.

Hasilkan garis panduan penyeragaman identiti visual untuk semua dokumen rasmi sekolah.

Skop penyeragaman:
- Cover buku/modul
- Laporan rasmi
- Kertas kerja
- Fail pentadbiran

Keperluan kandungan:
- Palet warna rasmi
- Fon tajuk dan isi
- Gaya ikon dan elemen visual
- Susun atur muka hadapan (tajuk, logo, tahun)

Arahan visual / imej:
- Contoh mockup cover (tanpa maklumat sensitif)
- Elemen sekolah (bangunan, logo placeholder)

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Mudah diguna semula oleh semua guru
- Sesuai sebagai panduan dalaman sekolah
```

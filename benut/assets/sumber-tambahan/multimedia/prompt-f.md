# 🅵 SEKSYEN F — MENCANTIKKAN KELAS & PERSEKITARAN SEKOLAH


## F1️⃣ Template Prompt — Visual Hiasan Kelas

*(Motivasi, Nilai Murni & Sahsiah)*

```
Anda ialah guru/pentadbir sekolah di Malaysia.

Hasilkan kandungan DAN cadangan visual untuk hiasan kelas bertema motivasi dan nilai murni.

Maklumat:
Tema utama        : [Motivasi / Nilai Murni / Sahsiah]
Sasaran murid     : [Tahun / Tingkatan]
Bilangan visual   : [3–5 poster ringkas]
Nada mesej        : [Positif, membina, tidak menghukum]

Keperluan kandungan:
- Ayat pendek, mudah difahami murid
- Elakkan ayat negatif atau terlalu panjang

Arahan visual / imej:
- Ilustrasi murid belajar, bekerjasama (imej generik)
- Ikon positif (bintang, hati, buku, lampu idea)
- Latar kelas cerah dan tenang

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai dicetak dan dilekatkan di dinding kelas
```

## F2️⃣ Template Prompt — Poster Peraturan Kelas & Budaya Positif

```
Anda ialah guru kelas / pentadbir sekolah.

Hasilkan poster peraturan kelas yang membina budaya positif.

Maklumat:
Tajuk poster      : [Peraturan Kelas Kami]
Bilangan peraturan: [5–7 peraturan]
Pendekatan        : [Galakan positif, bukan hukuman]

Keperluan kandungan:
- Gunakan ayat positif (contoh: “Datang awal”)
- Elakkan ayat berbentuk ancaman

Arahan visual / imej:
- Ilustrasi murid berdisiplin (imej generik)
- Ikon tanda betul, senyum, jam
- Warna lembut dan mesra murid

Reka bentuk:
- Mudah dibaca dari jauh
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk murid rendah & menengah
```

## F3️⃣ Template Prompt — Infografik Sudut Ilmu / Sudut Bacaan

```
Anda ialah guru sekolah.

Hasilkan infografik untuk Sudut Ilmu / Sudut Bacaan kelas.

Maklumat:
Nama sudut         : [Sudut Ilmu / Sudut Bacaan]
Fokus              : [Membaca / Fakta Menarik / Ilmu Harian]
Bilangan poin      : [4–6 poin ringkas]

Keperluan kandungan:
- Fakta atau mesej ringkas
- Bahasa mudah dan menarik

Arahan visual / imej:
- Ilustrasi buku, rak buku, murid membaca (imej generik)
- Warna ceria tetapi tidak terlalu terang
- Latar kelas atau perpustakaan mini

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk sudut bacaan fizikal
```

## F4️⃣ Template Prompt — Rekaan Visual Papan Kenyataan Kelas & Koridor

```
Anda ialah guru/pentadbir sekolah.

Hasilkan rekaan visual untuk papan kenyataan kelas atau koridor sekolah.

Maklumat:
Lokasi papan       : [Dalam kelas / Koridor]
Tujuan             : [Makluman / Paparan hasil murid / Info sekolah]
Tema               : [Akademik / Sahsiah / Aktiviti]

Keperluan kandungan:
- Tajuk jelas
- Ruang fleksibel untuk tampal bahan sebenar

Arahan visual / imej:
- Elemen visual sekolah (bangunan, kelas, ikon pendidikan)
- Elakkan latar terlalu sibuk
- Warna selaras dengan identiti sekolah

Reka bentuk:
- Modular (mudah ditukar isi)
- Ikut Standard Grafik Sekolah Malaysia
```

## F5️⃣ Template Prompt — Tema Visual Kelas

*(STEM, Literasi, Sahsiah dan lain-lain)*

```
Anda ialah guru/pentadbir sekolah.

Hasilkan cadangan tema visual lengkap untuk satu kelas.

Maklumat:
Nama tema          : [STEM / Literasi / Sahsiah / Patriotisme]
Tahap murid        : [Rendah / Menengah]
Komponen visual    : [Poster, sudut khas, papan kenyataan]

Keperluan kandungan:
- Huraikan konsep tema secara ringkas
- Cadangkan 4–6 elemen visual utama

Arahan visual / imej:
- Ilustrasi berkaitan tema (contoh: STEM → sains & teknologi)
- Gambar kelas / sekolah sebagai latar
- Elemen bendera Malaysia secara beradab (jika sesuai)

Reka bentuk:
- Menyokong PdP
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai digunakan sepanjang tahun
```

Daripada Data Sekolah kepada Visual Pengurusan

Gunakan data rekaan untuk menghasilkan infografik, poster ringkasan dan dashboard yang tepat serta mudah difahami oleh pentadbir sekolah.

Muat turun dataset ↓

Bahan diperlukan

Dataset prestasi akademik rekaan, Google Gemini dan pelayar web.

Hasil akhir

Data disahkan, infografik, poster, dashboard HTML dan laporan audit.

Contoh visual

Daripada data mentah kepada paparan pengurusan

Contoh ini membantu peserta membezakan sumber asal dengan hasil visual yang telah distrukturkan.

Perhatian: Kedua-dua imej menunjukkan jenis data yang berbeza. Gunakan imej pertama untuk memahami proses pengekstrakan dan imej kedua untuk memahami struktur hasil akhir.

Langkah 1

Audit fail sumber

Prompt audit data

Teliti dataset prestasi sekolah yang dimuat naik. Senaraikan helaian, lajur, jenis data, bilangan rekod, nilai kosong, pendua dan nilai luar julat. Hasilkan jadual isu dan cadangan pembetulan. Jangan buat tafsiran prestasi pada langkah ini.

Langkah 2

Sahkan kiraan

Prompt pengesahan

Kira semula purata, perubahan antara pentaksiran dan kedudukan kelas berdasarkan data sumber. Hasilkan DATA DISAHKAN V1 dalam jadual Kelas | Mata Pelajaran | Nilai Sumber | Nilai Dikira | Perbezaan | Status. Nyatakan formula yang digunakan.

Langkah 3

Pilih mesej utama

Prompt dapatan

Daripada DATA DISAHKAN V1, kenal pasti maksimum lima dapatan yang penting kepada pentadbir sekolah. Bezakan fakta, tafsiran berhati-hati dan cadangan. Jangan menyimpulkan sebab prestasi tanpa bukti.

Langkah 4

Hasilkan infografik

Prompt infografik

Hasilkan infografik menegak berasaskan DATA DISAHKAN V1. Paparkan tajuk, tiga KPI, satu carta, tiga dapatan dan nota sumber. Gunakan tema profesional sekolah berwarna biru navy, biru dan kuning keemasan. Semua angka mesti sama dengan data disahkan.

Langkah 5

Hasilkan poster ringkasan

Prompt poster

Tukar infografik yang diluluskan kepada poster ringkasan A4 untuk mesyuarat prestasi. Utamakan satu mesej utama, tiga angka penting dan tiga tindakan. Jangan padatkan poster dengan teks dan jangan tambah data baharu.

Langkah 6

Rancang dashboard

Prompt spesifikasi

Bina spesifikasi dashboard satu halaman untuk pentadbir sekolah. Sertakan KPI, penapis, jadual, carta trend, carta perbandingan, warna status dan tiga dapatan. Bagi setiap komponen, nyatakan medan sumber dan tujuan keputusan.

Langkah 7

Hasilkan dashboard HTML

Prompt pembangunan

Hasilkan dashboard statik menggunakan HTML, CSS dan JavaScript berdasarkan spesifikasi serta DATA DISAHKAN V1. Semua fail mesti menggunakan pautan relatif dan sesuai untuk GitHub Pages. Pastikan paparan responsif, label carta jelas dan tiada pustaka yang memerlukan kunci API.

Langkah 8

Audit semua hasil

Prompt audit akhir

Audit infografik, poster dan dashboard terhadap DATA DISAHKAN V1. Semak ketepatan angka, label, skala carta, konsistensi warna, keterbacaan, aksesibiliti dan fungsi pautan. Hasilkan matriks Output | Semakan | Status | Isu | Pembetulan.

Simpan: DATA DISAHKAN V1, infografik, poster, fail dashboard dan matriks audit.

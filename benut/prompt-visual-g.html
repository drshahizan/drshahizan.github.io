🅶 SEKSYEN G — VISUAL MURID & KOMUNITI SEKOLAH

G1. Template Prompt — Poster Motivasi Murid

Anda ialah guru/pentadbir sekolah di Malaysia.

Hasilkan kandungan DAN cadangan visual untuk poster motivasi murid.

Maklumat:
Tahap murid       : [Sekolah Rendah / Menengah]
Tema motivasi     : [Usaha, Disiplin, Keyakinan Diri, Cita-cita]
Bilangan poster   : [1–3 poster]
Nada mesej        : [Positif, membina, memberi semangat]

Keperluan kandungan:
- Ayat pendek dan mudah diingati
- Sesuai dengan tahap umur murid
- Elakkan ayat yang menekan atau menghukum

Arahan visual / imej:
- Ilustrasi murid belajar, berusaha atau berjaya (imej generik)
- Ikon bintang, anak panah naik, buku
- Latar sekolah atau kelas yang cerah

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Mudah dibaca dari jarak jauh
- Sesuai ditampal di kelas dan koridor

G2. Template Prompt — Visual Nilai Murni & Adab di Sekolah

Anda ialah pentadbir sekolah.

Hasilkan visual pendidikan berkaitan nilai murni dan adab di sekolah.

Maklumat:
Tema nilai        : [Hormat-menghormati, Amanah, Tanggungjawab, Kerjasama]
Sasaran           : [Murid / Warga sekolah]
Bilangan nilai    : [4–6 nilai]

Keperluan kandungan:
- Setiap nilai disertakan huraian 1 ayat
- Bahasa sopan dan mudah difahami

Arahan visual / imej:
- Ilustrasi murid beradab (beratur, memberi salam, bekerjasama)
- Ikon hati, tangan, senyum
- Elakkan visual berbentuk hukuman

Reka bentuk:
- Mesra murid dan menenangkan
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk paparan awam sekolah

G3. Template Prompt — Poster Kesedaran

(Anti-Buli, Disiplin, Keselamatan)

Anda ialah pentadbir sekolah.

Hasilkan poster kesedaran murid berkaitan isu keselamatan dan kesejahteraan.

Maklumat:
Tema kesedaran    : [Anti-Buli / Disiplin / Keselamatan]
Sasaran           : [Murid Rendah / Menengah]
Mesej utama       : [1–2 mesej ringkas]

Keperluan kandungan:
- Nada mendidik, bukan menakutkan
- Fokus kepada pencegahan dan sokongan

Arahan visual / imej:
- Ilustrasi situasi selamat dan positif (imej generik)
- Ikon perlindungan, peringatan, sokongan
- Elakkan visual ganas atau ekstrem

Reka bentuk:
- Kontras jelas untuk keterbacaan
- Aksen kuning untuk mesej penting
- Ikut Standard Grafik Sekolah Malaysia

G4. Template Prompt — Bahan Visual Sambutan Hari Kebesaran & Perayaan

Anda ialah pentadbir sekolah.

Hasilkan bahan visual bagi sambutan hari kebesaran atau perayaan di sekolah.

Maklumat:
Nama sambutan     : [Hari Kebangsaan / Hari Raya / Tahun Baru Cina / Deepavali]
Tarikh            : [Tarikh]
Sasaran           : [Murid / Ibu bapa / Komuniti]
Tujuan            : [Sambutan / Pendidikan / Perpaduan]

Keperluan kandungan:
- Bahasa sopan dan inklusif
- Tekankan nilai perpaduan dan hormat

Arahan visual / imej:
- Elemen simbolik perayaan (secara sederhana)
- Bendera Malaysia digunakan dengan beradab
- Elakkan stereotaip berlebihan

Reka bentuk:
- Ceria tetapi profesional
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk paparan awam dan digital

G5. Template Prompt — Poster Jati Diri Sekolah & Aspirasi Murid

Anda ialah pentadbir sekolah.

Hasilkan poster berkaitan jati diri sekolah dan aspirasi murid.

Maklumat:
Moto sekolah      : [Moto]
Visi / Aspirasi   : [Ringkasan]
Sasaran           : [Murid / Warga sekolah]
Nada mesej        : [Bangga, positif, berwawasan]

Keperluan kandungan:
- Ayat ringkas dan berimpak
- Selari dengan identiti sekolah

Arahan visual / imej:
- Latar sekolah atau aktiviti rasmi (imej generik)
- Ikon kejayaan, masa depan, bintang
- Elemen warna sekolah digunakan konsisten

Reka bentuk:
- Ikut Standard Grafik Sekolah Malaysia
- Sesuai untuk paparan utama sekolah
- Digunakan sepanjang tahun

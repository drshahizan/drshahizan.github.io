# Kursus AI untuk Pentadbir Sekolah

Website statik untuk GitHub Pages.

## Cara menerbitkan

1. Muat naik semua kandungan folder ini ke repositori GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, cabang `main`, folder `/ (root)`.
4. Simpan dan tunggu pautan GitHub Pages diaktifkan.

Website menggunakan HTML, CSS dan JavaScript biasa tanpa proses pemasangan.

01

Salin website Projek 1 DB

Letakkan semua fail pada lokasi yang betul dalam repositori.

  1. Muat turun pakej Projek 1 DB.
  2. Ekstrak fail ZIP.
  3. Salin keseluruhan folder projek1-db ke dalam folder demo.
  4. Pastikan fail demo/projek1-db/index.html wujud.
jkr/ └── demo/ └── projek1-db/ ├── index.html ├── dashboard.html ├── dokumen/ ├── google-apps-script/ ├── js/ └── css/
✓ Website boleh dibuka melalui https://drshahizan.github.io/jkr/demo/projek1-db/ selepas dihantar ke GitHub.
02

Salin pangkalan data ke Google Drive

Gunakan templat yang telah mempunyai tab, tajuk medan dan data latihan.

Muat turun templat pangkalan data
  1. Buka Google Drive dan klik New > File upload.
  2. Pilih fail Pangkalan_Data_Portal_Aduan_JalanCare.xlsx.
  3. Klik kanan fail yang telah dimuat naik.
  4. Pilih Open with > Google Sheets.
  5. Pilih File > Save as Google Sheets.
  6. Namakan fail JalanCare Projek 1 DB — Nama Peserta.
✓ Anda mempunyai salinan Google Sheets sendiri. Jangan gunakan fail milik peserta lain.
03

Semak struktur Google Sheets

Nama tab mesti dikekalkan kerana Apps Script merujuk nama tersebut.

Tab operasi

  • DASHBOARD
  • ADUAN
  • TINDAKAN
  • TUGASAN

Tab sistem

  • TETAPAN
  • PENGGUNA
  • KATEGORI
  • SESI
  • LOG_AKTIVITI

Jangan menukar nama tab, memadam baris tajuk atau menyusun semula kolum pada peringkat ini.

✓ Kesemua sembilan tab wujud dan data contoh boleh dilihat.
04

Buka Google Apps Script

Cipta bahagian perantara antara website dan Google Sheets.

  1. Dalam Google Sheets, klik Extensions > Apps Script.
  2. Tukar nama projek kepada JalanCare Projek 1 DB.
  3. Buka fail Code.gs.
  4. Padam fungsi contoh myFunction().
✓ Editor Apps Script kosong dan bersedia menerima kod Projek 1.
05

Kemas kini Code.gs

Salin kod API yang telah disediakan dalam website Projek 1.

Buka fail Code.gs
  1. Buka fail demo/projek1-db/google-apps-script/Code.gs.
  2. Salin keseluruhan kandungan fail.
  3. Tampal ke editor Apps Script.
  4. Klik Save.
  5. Pastikan tiada tanda merah atau mesej ralat sintaks.

Prompt bantuan jika berlaku ralat

✓ Code.gs telah disimpan tanpa ralat sintaks.
06

Terbitkan sebagai Web App

Benarkan website menghantar dan membaca data melalui URL Web App.

  1. Klik Deploy > New deployment.
  2. Klik ikon gear dan pilih Web app.
  3. Description: JalanCare API v1.
  4. Execute as: Me.
  5. Who has access: Anyone.
  6. Klik Deploy dan benarkan akses yang diminta.
  7. Salin URL yang berakhir dengan /exec.
Penting: Gunakan URL /exec, bukan URL /dev. Simpan URL ini sementara kerana ia akan dimasukkan ke dalam website.
✓ Google memberikan satu Web App URL kepada anda.
07

Uji sambungan API

Pastikan Apps Script aktif sebelum mengubah website.

Tambah ?action=ping selepas URL Web App:

https://script.google.com/macros/s/ID_ANDA/exec?action=ping

Buka URL tersebut dalam pelayar. Respons yang betul ialah:

{"ok":true,"message":"JalanCare API aktif","version":"2.0"}
✓ Jika "ok":true dipaparkan, Google Sheets dan Apps Script telah berjaya disambungkan.
08

Sambungkan website kepada Web App

Masukkan URL Web App ke dalam satu fail konfigurasi sahaja.

  1. Buka demo/projek1-db/js/config.js menggunakan VS Code atau penyunting teks.
  2. Cari MASUKKAN_URL_GOOGLE_APPS_SCRIPT_WEB_APP.
  3. Gantikan teks tersebut dengan URL /exec anda.
  4. Jangan padam tanda petik.
  5. Simpan fail.
window.JALANCARE_CONFIG = { API_URL: "https://script.google.com/macros/s/ID_ANDA/exec", APP_NAME: "JalanCare", API_VERSION: "2.0", REQUEST_TIMEOUT_MS: 20000 };
✓ Website kini mengetahui lokasi Google Apps Script anda.
09

Hantar perubahan melalui GitHub Desktop

Kemas kini GitHub Pages menggunakan proses visual.

  1. Buka GitHub Desktop dan pilih repositori jkr.
  2. Pastikan perubahan pada folder demo/projek1-db disenaraikan.
  3. Masukkan Summary: Tambah Projek 1 DB Google Sheets.
  4. Klik Commit to main.
  5. Klik Push origin.
  6. Tunggu GitHub Pages mengemas kini website.
✓ Website diterbitkan pada https://drshahizan.github.io/jkr/demo/projek1-db/.
10

Laksanakan ujian akhir

Uji keseluruhan perjalanan pengguna dan pastikan Google Sheets berubah.

Ujian awam

  1. Buka Buat Aduan dan hantar satu aduan.
  2. Catat nombor rujukan dan kod semakan empat digit.
  3. Semak tab ADUAN dalam Google Sheets.
  4. Gunakan halaman Semak Status.

Ujian staf

  1. Log masuk menggunakan admin / Admin@123.
  2. Semak dashboard dan senarai aduan.
  3. Buka butiran aduan dan kemas kini status.
  4. Pastikan tab ADUAN, TINDAKAN dan LOG_AKTIVITI berubah.
✓ Projek 1 Fasa 2 selesai apabila data boleh dihantar, dibaca dan dikemas kini dari GitHub Pages.
?

Penyelesaian masalah biasa

Semak bahagian ini sebelum mengubah kod.

“URL belum dikonfigurasi”

Semak js/config.js dan pastikan URL berakhir dengan /exec.

“Authorization required”

Deploy semula dengan Execute as Me dan akses Anyone.

Data tidak masuk

Pastikan nama sembilan tab tidak berubah dan fail telah disimpan sebagai Google Sheets.

Kod diubah tetapi tiada kesan

Pilih Deploy > Manage deployments > Edit > New version > Deploy.

Website masih versi lama

Pastikan GitHub Desktop sudah Push origin, tunggu beberapa minit dan muat semula halaman.

Login gagal

Gunakan huruf besar/kecil kata laluan dengan tepat: Admin@123.

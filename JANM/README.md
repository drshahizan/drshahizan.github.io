# Pemerkasaan AI dalam Pengoperasian Pejabat

Versi ini turut menyediakan halaman berasingan `ai-tools.html`, `prompt-ai.html`, `panduan-ai.html`, `sumber.html` dan `penggunaan-peralatan.html` supaya kandungan tidak terlalu panjang. Semua fail perlu dimuat naik ke root repositori bersama folder `assets` dan `modules`.

Laman statik HTML, CSS dan JavaScript untuk GitHub Pages.

## Struktur

- `index.html` — halaman utama
- `style.css` — reka bentuk responsif
- `script.js` — menu, tab tentatif dan butang kembali ke atas
- `assets/images/` — semua visual program dan modul
- `modules/` — halaman ringkas Modul 1 hingga Modul 5

## Terbitkan di GitHub Pages

1. Ekstrak fail ZIP.
2. Muat naik semua kandungan folder ini ke bahagian root repositori GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/root`.
5. Klik **Save**.

Pastikan struktur folder tidak diubah supaya semua imej dan pautan relatif terus berfungsi.

THE PROGRAMME

Five days.
One connected journey.

From prompt engineering to a database-enabled application, each day introduces a new capability and adds a practical output to the portfolio.

9:00 a.m. – 5:00 p.m. dailyFive guided workshop daysIndicative programme
05

HOW THE DAYS CONNECT

Learn it. Apply it.
Show what it can do.

The programme moves from AI foundations and responsible use into creative production, data analysis and application development. Participants build through guided activities and a shared Malaysian service scenario.

Daily outputs are designed to be practical. Tools and activities can be adjusted to suit participants’ experience.

THE FIVE-DAY PROGRAMME

Choose a day to view its schedule and learning output.

DAILY · 9:00 A.M.–5:00 P.M.
01

THINK WITH AI

AI Foundations, Prompt Engineering
and an Agentic AI Case Study

FOCUS

Use generative AI effectively and understand how an AI agent can support a client service workflow.

9:00–9:30Welcome, workshop objectives and participant service scenarios
9:30–10:30Generative AI and large language models: capabilities, limitations and practical use
10:30–10:45Coffee break
10:45–12:30Prompt engineering: context, instructions, examples, output formats and iterative refinement
12:30–1:30Lunch break
1:30–2:15Responsible AI: output verification, bias, privacy, copyright and data handling
2:15–3:00Agentic AI explained: how an agent uses information and tools to complete a multi-step task
3:00–3:15Coffee break
3:15–4:30Case study and demonstration: an AI agent helps an SME process service requests, consult approved service information and draft a response
4:30–5:00Map the case-study workflow: data sources, permitted actions and human approval points
↗
DAY 1 OUTPUTA reusable prompt workflow and an agentic AI case-study map.

The case study is a guided analysis and demonstration; participants are not expected to build a production agent.

Open Day 1 exercises →
02

TELL THE STORY

AI-Assisted Video Production
and Showcase

FOCUS

Take a client brief from idea to a finished, exported video, then showcase the week’s work.

9:00–10:30Define video purpose and audience; develop the idea, script and storyboard
10:30–10:45Coffee break
10:45–12:30Prepare video scenes and visual assets, reusing suitable assets created
12:30–1:30Lunch break
1:30–3:00Generate or record voice-over and audio; assemble the video sequence
3:00–3:15Coffee break
3:15–4:00Edit the video, add captions and titles, and export the final version
4:00–5:00Showcase, peer feedback and workshop wrap-up
↗
DAY 2 OUTPUTA short edited video for a product, service or organisation.

Participants briefly present the client problem addressed and the service their output could support.

Open Day 2 exercises →
03

DESIGN WITH AI

AI Image Generation
and Graphic Design

FOCUS

Turn a client brief into a consistent, on-brand set of visual materials.

9:00–10:30Client brief, target audience, purpose, brand direction and visual moodboard
10:30–10:45Coffee break
10:45–12:30Writing image prompts and generating visual assets for a product, service or organisation
12:30–1:30Lunch break
1:30–3:00Refining images: composition, style consistency, background editing and product mockups
3:00–3:15Coffee break
3:15–4:30Designing a main promotional graphic and adapting it for another digital channel
4:30–5:00Quality check, export formats, editable-file handover and appropriate-use review
↗
DAY 3 OUTPUTA mini visual guide, three selected concept images, a one-page A4 brochure and a landscape banner variation.

Participants treat AI images as illustrative concepts, verify all claims and add final text in a design editor.

Open Day 3 exercises →
04

MEASURE AND LAUNCH

Data Dashboard and Web Development,
Part 1

FOCUS

Analyse simulated visit sessions by country and month, build a dashboard and static website, then connect a web app to Google Sheets.

9:00–10:30Define data questions, inspect dataset structure and quality, and select useful measures
10:30–10:45Coffee break
10:45–12:30Prepare and analyse 6,000 simulated visitor sessions; create a country Geo chart, monthly filter and dashboard charts
12:30–1:30Lunch break
1:30–3:00Web Level 1: plan and build a static business website with clear page structure, user flow and a responsive interface
3:00–3:15Coffee break
3:15–4:30Web Level 2: build an Apps Script web app that saves simulated enquiries in Google Sheets and shows a confirmation
4:30–5:00Test the dashboard, static website and Sheets-backed web app from a user’s perspective
↗
DAY 4 OUTPUTA visitor dashboard with a country map and month selector, a static website and a Google Sheets enquiry form that saves a practice request and returns a confirmation.

Day 4 stores practice enquiries in Google Sheets. Day 5 uses a separate Supabase project for the manager booking app.

Open Day 4 exercises →
05

BUILD

Web Development, Part 2:
Supabase Booking Application

FOCUS

Turn the Day 3 promotional kit and Day 4 website work into a Supabase-backed homestay enquiry and booking prototype.

9:00–10:30Map the visitor and manager journeys; prepare the Supabase project, booking fields and table
10:30–10:45Coffee break
10:45–12:30Check Row Level Security and connect the package page and enquiry form to Supabase
12:30–1:30Lunch break
1:30–3:00Implement the visitor enquiry form and manager view for booking requests
3:00–3:15Coffee break
3:15–4:30Add status update and delete actions; validate inputs and troubleshoot with AI assistance
4:30–5:00Demonstrate the visitor-to-manager flow; review access rules and deployment considerations
↗
DAY 5 OUTPUTA Mersing homestay package and enquiry app with a Supabase booking manager and create, read, update and delete actions.

Reuse Day 3 visuals and Day 4 page structure. Use simulated booking records, check the RLS policy and keep secret keys out of browser code.
